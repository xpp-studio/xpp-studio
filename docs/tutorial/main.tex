\begin{abstract}
\noindent \XS{} is a browser-based environment for exploring dynamical systems, modelled on Bard Ermentrout's \XPP{}. It reads \XPP{}'s \texttt{.ode} files and provides phase planes, three-dimensional views, time courses, numerical continuation of equilibria and periodic orbits, one- and two-parameter bifurcation diagrams, maps, stochastic and Markov models, stiff solvers, delay equations, events (global flags), boundary value problems, arrays and Volterra integral equations. Everything runs locally in a web page: there is nothing to install and no data leaves the browser. This document introduces the interface, describes the model language, and works through a sequence of short tutorials using the examples that come with the program.
\end{abstract}

\section{Introduction}

For more than thirty years \XPP{} \cite{ermentrout2002} has been one of the standard tools for simulating and analysing differential equations in mathematical biology, neuroscience and applied dynamical systems. Its strengths are a compact, readable model language, fast interactive phase-plane analysis, and a tight connection to the continuation package \textsf{AUTO} \cite{doedel2007}. \XS{} keeps that model language and that way of working, and puts them in a modern interface:

\begin{itemize}
  \item \textbf{Same files.} Most \XPP{} \texttt{.ode} files load unchanged. Supported features include parameters, functions, fixed quantities, auxiliary variables, maps, Wiener noise, Markov variables, tables, periodic (folded) variables, arrays, Volterra integrals, delays, global flags and boundary conditions (Section~\ref{sec:language}).
  \item \textbf{Live analysis.} Dragging a parameter slider immediately recomputes trajectories, nullclines and equilibria.
  \item \textbf{Built-in continuation.} Equilibria, periodic orbits and their bifurcations can be continued in one or two parameters without leaving the program. Detected points include folds, Hopf, period-doubling, torus, fold-of-cycles and codimension-two points.
  \item \textbf{Publication output.} Every view can be exported as a vector SVG figure. Continuation data can be exported as CSV, and trajectories copied as CSV.
\end{itemize}

\noindent The program is a single web page. To use it, open
\begin{center}
  \url{\xppurl}
\end{center}
in any recent browser. The source code, the example models and this tutorial are in the repository \url{\xppgit}. Its file \texttt{index.html} is the whole program, and it also runs when opened directly from disk.

\paragraph{How this document is organised.} Section~\ref{sec:tour} is a tour of the interface and Section~\ref{sec:language} summarises the model language. Sections~\ref{sec:pp}--\ref{sec:volterra} are hands-on tutorials, each built on an example from the \ui{Model} menu. Section~\ref{sec:script} shows how to record and replay the steps behind a set of figures with a script. Sections~\ref{sec:torus} and~\ref{sec:conn} are two further tutorials, on a forced oscillator and on homoclinic and heteroclinic orbits. Section~\ref{sec:numerics} covers numerical settings and Section~\ref{sec:export} exporting results. The document ends with the differences from \XPP{} and with credits.

\begin{figure}[!htbp]
  \centering
  \includegraphics[width=\textwidth]{ui-overview.png}

Centre: the plot, here the $(v,w)$ phase plane with nullclines, five trajectories and a stable focus, plus a time-course strip underneath. Right: the inspector, listing equilibria, the variables shown in the time course, and the trajectories.}
  \label{fig:overview}
\end{figure}

The window (Figure~\ref{fig:overview}) has three columns.

\paragraph{Left: the model.} Five tabs:
\begin{description}[font=\sffamily\bfseries]
  \item[Equations] The \texttt{.ode} text, which you can edit freely. \ui{Apply} (or \key{Ctrl}+\key{Enter}) reloads the model, and messages underneath report what was loaded and any errors, with line numbers. \ui{Open .ode} loads a file from disk, \ui{Copy text} copies the current text, \ui{Write state} writes the current parameters, initial conditions and settings into it (Section~\ref{sec:writestate}), and \ui{Table files} supplies data files used by \texttt{table} declarations.
  \item[Parameters] One row per parameter, with a value box and a slider whose limits you can edit. Drag a slider to see everything update live, and use \ui{Reset} to restore the values in the file. The up and down arrows on a value box, and the arrow keys on a slider, change the value by 1\% of the slider's range (10\% with \key{Shift}).
  \item[Initial] Initial values of the state variables (and Markov states). \ui{Integrate} runs from here, and \ui{Last point $\to$ IC} copies the end of the current trajectory into the initial conditions.
  \item[Numerics] Integration method, total time, transient, step size, tolerance and bound, plus the continuation settings (Section~\ref{sec:numerics}).
  \item[Script] A list of commands that drives the interface, to make a set of figures again exactly, with one click (Section~\ref{sec:script}).
\end{description}

\paragraph{Centre: the plot.} Five views, chosen with the buttons above the plot or with the keys \key{1}--\key{5}:
\begin{description}[font=\sffamily\bfseries]
  \item[Phase plane] Any two variables (state, Markov, Volterra or auxiliary) against each other, with optional nullclines, direction field and equilibria. For a one-dimensional map this view shows a cobweb diagram. \ui{Equal axes} gives both axes the same scale. \ui{Run grid} in the Initial tab starts trajectories from a grid of points, by default covering the window (Section~\ref{sec:many}). Below the plane a strip shows the time series of the current trajectory.
  \item[3D] Three variables (or time) in a rotatable box: drag to rotate, scroll to zoom, \ui{Spin} to animate.
  \item[Time course] Chosen variables against $t$ (or the iteration number $n$ for maps). \ui{Spectrum} shows their power spectra instead, and \ui{Space-time} shows a row of indexed variables as an image (Section~\ref{sec:spacetime}).
  \item[Bifurcation] Branches of equilibria and periodic orbits, parameter sweeps, and homoclinic and heteroclinic orbits, against one parameter. The vertical axis is a variable, or the period or frequency of the periodic orbits.
  \item[Two-parameter] Curves of folds, Hopf points, period doublings and bifurcations of cycles in a parameter plane.
\end{description}
\paragraph{The status line} at the bottom of the window reports what the last action did: how many points a trajectory has, why a branch stopped, where a special point was found. \ui{History}, at its right-hand end, lists every message since the page was opened, each with its time, so that a report that has scrolled away can be read again. Progress reports during a long computation are kept as one line, the last one. \ui{Download} saves the list as a text file, \ui{Copy} copies it and \ui{Clear} empties it; in a script, \texttt{history save} does the same (Section~\ref{sec:script}).

In every view you drag to pan and scroll to zoom. \ui{Fit} rescales to the data, and \ui{Window} sets the axis limits by hand (they then stay fixed until you press \ui{Fit}). \ui{Points} draws trajectories as dots instead of lines, which is the default for maps. \ui{Export SVG} saves the current view as a vector figure. \ui{Export CSV} saves the data behind the time course, bifurcation diagram or two-parameter diagram, and \ui{Export .dat} saves continuation data as plain columns of numbers (Section~\ref{sec:export}).

\paragraph{Labelling a plot.}\label{sec:notes} The \ui{Note} chip above the plot puts a text label on the figure. It appears in the phase plane, the time course (including the spectrum and the space-time plot), the Bifurcation view and the two-parameter plane, but not in the 3D views. Press it, click the plot where the label should go, and type the text in the small box that opens; a new line in the box starts a new line of text. The box also sets the size (small, medium or large) and the colour: the ordinary text colour, the accent, one of the colours used for curves and trajectories, or any colour from the colour picker. Close the box with \ui{Done}, \key{Ctrl}+\key{Enter}, \key{Esc} or a click elsewhere; a note with no text is discarded.
\begin{itemize}
  \item \textbf{Move, edit, delete.} Drag a note to move it, double-click it to edit it, or click it to select it and press \key{Delete}. \ui{Delete} in the editing box removes it too.
  \item \textbf{Notes belong to a plot.} A note is placed in the data coordinates of the plot it was made on, so it stays on its feature when you pan and zoom. It is shown only on that plot: the phase plane of that pair of variables, the diagram for that continuation parameter and vertical axis, or that parameter plane. Switch to other axes and the note is hidden, and it comes back when you return. Loading another model removes all notes.
  \item \textbf{In figures and scripts.} Notes are drawn in \ui{Export SVG}, in the colours of the light theme, along with the legend. A note you make while recording is written into the script as a \texttt{note} line (Section~\ref{sec:script}). Notes are not saved in the \texttt{.ode} file.
\end{itemize}

\paragraph{Right: the inspector.} The inspector's contents depend on the view. In the phase plane it lists the equilibria (type, coordinates and eigenvalues, with buttons to make one the initial condition, start continuation from it, or draw its separatrices), the variables in the time course, and the trajectories. For large systems, and for boundary value problems, equilibria are not searched for automatically; \ui{Find} next to the list searches the visible window when you want them. In the Bifurcation view it holds the continuation controls, the search for homoclinic and heteroclinic orbits, and the table of special points. In the Two-parameter view it holds the two-parameter controls.

\section{The model language}\label{sec:language}

A model is a plain-text \texttt{.ode} file in \XPP{}'s format. Lines starting with \texttt{\#} are comments, and the first comment line becomes the model's title. Names are case-insensitive. The Morris--Lecar example \cite{morris1981,rinzel1989} illustrates most of the basic syntax:

\begin{lstlisting}
# Morris-Lecar neuron, Hopf regime (Rinzel & Ermentrout)
dv/dt=(i+gl*(vl-v)+gk*w*(vk-v)+gca*minf(v)*(vca-v))/c
dw/dt=phi*(winf(v)-w)/tauw(v)
minf(v)=.5*(1+tanh((v-v1)/v2))
winf(v)=.5*(1+tanh((v-v3)/v4))
tauw(v)=1/cosh((v-v3)/(2*v4))
aux ica=gca*minf(v)*(v-vca)
param i=60,c=20
param vk=-84,vl=-60,vca=120
param gk=8,gl=2,gca=4.4
param v1=-1.2,v2=18,v3=2,v4=30,phi=.04
init v=-60,w=0.015
#@range i 0 300
@ total=400,dt=0.25,meth=rk4,xp=v,yp=w
@ xlo=-75,xhi=45,ylo=-0.1,yhi=0.55
done
\end{lstlisting}

\noindent Table~\ref{tab:syntax} summarises the language. The \texttt{\#@range} line is an \XS{} extension that sets a slider's range. Because it starts with \texttt{\#}, \XPP{} reads it as a comment, so files stay portable.

\begin{notebox}
\textbf{Methods.} \texttt{meth=} accepts \texttt{rk4} (fixed-step Runge--Kutta), \texttt{euler}, \texttt{dp45} (adaptive Dormand--Prince 4(5)), and the stiff names \texttt{stiff}, \texttt{gear}, \texttt{cvode}, \texttt{rosenbrock} and \texttt{backeul}. All of the stiff names select an adaptive Rosenbrock 2(3) solver \cite{shampine1997}. \texttt{discrete} iterates a map. Models with Wiener variables always use Euler--Maruyama, and models with Volterra integrals use a product-trapezoid scheme.
\end{notebox}

\section{Tutorial 1: phase-plane analysis}\label{sec:pp}

\begin{figure}[!htbp]
  \centering
  \includegraphics[width=0.75\textwidth]{ml-phaseplane.pdf}
  \caption{Morris--Lecar phase plane at $i=60$: the $v$-nullcline (orange), the $w$-nullcline (green), a stable focus (filled circle) and several trajectories. Open circles mark starting points.}
  \label{fig:mlpp}
\end{figure}

Choose \ui{Morris--Lecar} from the \ui{Model} menu. The phase plane shows $w$ against the membrane potential $v$, together with the two nullclines.

\begin{tryit}
\begin{enumerate}
  \item Click anywhere in the plane to start a trajectory there. Shift-click integrates in both directions of time. Each new trajectory gets its own colour and appears in the \ui{Trajectories} list, where you can remove it with~$\times$.
  \item Press \key{D} for the direction field and \key{N} to hide or show the nullclines. Hovering over the plot shows the coordinates and the derivatives $v'$, $w'$ at the pointer.
  \item The inspector lists one equilibrium, a \emph{stable focus}, with its eigenvalues $\lambda\approx-0.055\pm0.063i$. \ui{Set as IC} moves the initial condition onto it.
  \item Open the \ui{Parameters} tab and slowly drag the slider for the applied current~$i$. Between about $i=94$ and $i=212$ the focus becomes unstable and trajectories settle onto a large limit cycle: repetitive firing.
  \item Press \key{3} for the time course. The chips in the inspector choose which variables are plotted, auxiliary ones included (\texttt{ica} here).
  \item To label the figure, press \ui{Note}, click next to the stable focus and type \texttt{stable focus}. Drag the label where you want it, and choose a colour in the box if you like. Labels are explained in Section~\ref{sec:notes}.
\end{enumerate}
\end{tryit}

\noindent Equilibria are found by Newton's method from a grid of starting points covering the visible window, so panning or zooming out searches a wider region. For a saddle, the \ui{Separatrices} button integrates its stable and unstable manifolds. Once drawn, they follow the saddle: when you change a parameter, the saddle is found again and its separatrices are recomputed from its new position, so you can watch, for example, a separatrix approach a homoclinic connection as you drag a slider.

\paragraph{Direction.} A run can go forward in time, backward, or in both directions. Choose this in the \ui{Initial} tab, next to \ui{Integrate}, or under \ui{Direction} in the Numerics tab; the two stay in step. \emph{Both} integrates backward and forward from the same point and joins the two halves into one trajectory, with $t$ running from $-T$ to $T$, so the time course and the arrow on the phase plane show it as a single curve. Trajectories run backward are marked $\leftarrow$ in the list and those run both ways $\leftrightarrow$. Shift-clicking the plane always runs both ways. Maps, delay and Volterra equations run forward only.

\paragraph{Several initial conditions.} \XPP{}'s \emph{Initialconds › Range} and \emph{Flow} integrate from many starting values at once. In \XS{} both are done by the \ui{Several initial conditions} section of the \ui{Initial} tab (Figure~\ref{fig:gridui}). Choose one or two variables, each with a start value, an end value and a number of steps, then press \ui{Run grid}; every combination is run, in the chosen direction, while the other variables keep their values from the list above.

By default the grid is $10\times10$ over the phase-plane window, using the two plotted variables and their axis limits, which gives a quick picture of the whole phase portrait (Figure~\ref{fig:grid}, right). These defaults follow the axes and window as you change them, until you edit a value yourself; \ui{Use window} goes back to them. Set the second variable to \emph{(none)} for a single row of starting points. The runs share one colour and appear in the trajectory list, \ui{Stop} ends a long grid early, and \key{E} erases the result. Figure~\ref{fig:grid} (left) shows a $7\times7$ grid on the toggle switch.

\section{Tutorial 2: one-parameter bifurcation diagrams}\label{sec:bif}

\begin{figure}[!htbp]
  \centering
  \includegraphics[width=0.72\textwidth]{ml-bifurcation.pdf}
  \caption{Bifurcation diagram of Morris--Lecar in the current~$i$. Black: equilibria (solid stable, dashed unstable). Green: maximum and minimum of $v$ along the periodic orbits born at the two Hopf points HB1 and HB2. Both Hopf bifurcations are subcritical. The orbit family turns at two folds of cycles, LPC1 and LPC2, giving bistability between rest and firing.}
  \label{fig:mlbif}
\end{figure}

Press \key{4} for the Bifurcation view. The inspector shows the continuation controls: the \ui{Parameter} to vary, the variable to \ui{Plot}, the parameter \ui{Range}, the initial step \ui{Step ds}, and the equilibrium to \ui{Start} from.

\begin{tryit}
\begin{enumerate}
  \item Press \ui{Continue equilibria}. Pseudo-arclength continuation \cite{keller1977} traces the branch in both directions across the range. Stability is read off the eigenvalues, and two Hopf points appear: HB1 at $i\approx 93.68$ (period $\approx 79.2$) and HB2 at $i\approx 212.06$. Each Hopf point is tagged \emph{sub} or \emph{super} in the \ui{Special points} table (Figure~\ref{fig:special}). The tag comes from the sign of the first Lyapunov coefficient $\ell_1$, and hovering over it shows the value. Both points here are subcritical ($\ell_1>0$), so the orbits born there are unstable.
  \item In the \ui{Special points} table, press \ui{Cycles} on the row for HB1. The periodic orbits born there are computed by multiple shooting with an integral phase condition, as in \textsf{AUTO}, and their stability comes from Floquet multipliers. While the computation runs, \key{Esc} (or \ui{Skip direction}) abandons the current direction and moves on, and \key{Shift}+\key{Esc} stops altogether.
  \item The family of orbits connects HB1 to HB2 and turns at two folds of cycles: LPC1 at $i\approx 88.29$ and LPC2 at $i\approx 216.90$ (Figure~\ref{fig:mlbif}). Between LPC1 and HB1 a stable orbit and the stable rest state coexist.
  \item Click any point of a branch to jump there. This sets the parameter and loads that equilibrium, or exactly one period of that orbit, as the current state. Clicking a row of the special-points table does the same.
  \item \ui{Limit cycle} starts orbit continuation from the current trajectory instead. Integrate onto a stable cycle first (e.g.\ at $i=150$), then press it.
  \item \ui{Show} sets what the vertical axis measures for the variable chosen under \ui{Plot}. The default \emph{hi-lo} draws the maximum and minimum of the variable over each orbit. \emph{L2 norm} draws $\bigl(\frac1T\int_0^T x(t)^2\,dt\bigr)^{1/2}$ over each orbit, and $|x|$ at each equilibrium, so a branch of orbits becomes a single curve that leaves the equilibrium branch at the Hopf point (Figure~\ref{fig:mll2}). The norms are computed the first time you choose this, by integrating one period of each orbit. \emph{Period} and \emph{frequency} draw the period of the orbits, or its inverse, against the parameter (Figure~\ref{fig:mlperiod}). The period grows from about 79 at HB1 to 135 at LPC1 and is about 42 at HB2. Sweeps show their periods too, where the oscillation is regular enough for one to be estimated. Changing \ui{Show} or \ui{Plot} refits only the vertical axis, to the data in the range of the parameter on screen, so a part of the diagram you have zoomed into stays in view as you switch between hi-lo, L2 norm and period.
  \item Click a point on the orbit branch. As well as loading that orbit, this adds it to the \ui{Special points} table as OR1, marked on the diagram with an open circle (Figure~\ref{fig:mlorbits}). \begin{notebox}
\textbf{Sub- or supercritical?} At a Hopf point with eigenvalues $\pm i\omega$, \XS{} computes the first Lyapunov coefficient
\[
\ell_1=\frac{1}{2\omega}\,\mathrm{Re}\Bigl[\langle p,C(q,q,\bar q)\rangle-2\langle p,B(q,A^{-1}B(q,\bar q))\rangle+\langle p,B(\bar q,(2i\omega I-A)^{-1}B(q,q))\rangle\Bigr],
\]
where $A$ is the Jacobian, $Aq=i\omega q$, $A^{\mathsf T}p=-i\omega p$ and $\langle p,q\rangle=1$ \cite{kuznetsov2004}. The multilinear forms $B$ and $C$ (the second and third derivatives of the vector field) are evaluated by finite differences. If $\ell_1<0$ the bifurcation is \emph{supercritical}: a small stable orbit appears on the side where the equilibrium is unstable. If $\ell_1>0$ it is \emph{subcritical}: an unstable orbit appears on the side where the equilibrium is stable, and the system usually jumps to a distant attractor.
\end{notebox}

\begin{notebox}
\textbf{What is detected.} For equilibria of flows: folds (LP), Hopf points (HB, tagged sub- or supercritical) and branch points (BP). For periodic orbits: folds of cycles (LPC), period doublings (PD) and torus (Neimark--Sacker) points (TR). For fixed points of maps: LP, PD and Neimark--Sacker (NS). At a PD of cycles, \ui{Double} switches to the period-doubled branch, and at a branch point \ui{Switch} follows the other branch through it. A branch that comes back to its starting point, such as an isola, is closed into a loop and reported as such.
\end{notebox}

\paragraph{Arrays.} \XPP{}'s arrays are a text macro. The \ui{Chain of 20 FitzHugh--Nagumo cells} example is written as
\begin{lstlisting}
%[1..20]
v[j]'=v[j]-v[j]^3/3-w[j]+i1*heav(1.5-[j])+d*(v[j+1]-2*v[j]+v[j-1])
%
w[1..20]'=eps*(v[j]+a-b*w[j])
v0=v1
v21=v20
init v[1..20]=-1.2
init w[1..20]=-0.62
\end{lstlisting}
The block between \texttt{\%[1..20]} and \texttt{\%} is repeated for $j=1,\ldots,20$. Every \texttt{[expr]} is replaced by its integer value, so \texttt{v[j-1]} becomes \texttt{v3} when $j=4$, and \texttt{[j]} on its own becomes the number~$j$. A single line containing \texttt{[1..20]} is repeated the same way. The load message reports how many lines the file expanded to. The expanded model is an ordinary 40-dimensional system, so its equilibria, eigenvalues (computed by the QR algorithm) and continuation all work as usual. In Figure~\ref{fig:arrays} (left) the time course shows $v_1$, $v_{10}$ and $v_{20}$; choose them with the chips in the inspector.

\paragraph{Space-time plots.}\label{sec:spacetime} For a chain or lattice it is often clearer to see all the cells at once, as in \XPP{}'s array plot. In the Time course view, \ui{Space-time} draws a row of indexed variables as an image, with time across and the cell index up (Figure~\ref{fig:spacetime}). Each point is coloured by its value, and a colour bar shows the range. A \emph{row} is any set of at least six variables with a common name and consecutive numbers, such as $v_1,\ldots,v_{20}$; when a model has several rows, \ui{show} chooses between them. \ui{colour min} and \ui{max} fix the colour range, and \ui{Auto} returns to the range of the run. In the chain the travelling pulses appear as stripes, and their slope is the propagation speed.

\begin{figure}[!htbp]
  \centering
  \includegraphics[width=0.62\textwidth]{chain-spacetime.pdf}
  \caption{Space-time plot of $v_1,\ldots,v_{20}$ for the chain of FitzHugh--Nagumo cells. Each pulse starts at cell 1 and crosses the chain in about 20 time units.}
  \label{fig:spacetime}
\end{figure}

\paragraph{Spectra.} \ui{Spectrum} in the Time course view replaces the time series by the power spectrum of each chosen variable, as amplitude against frequency (cycles per unit of $t$). A sinusoid of amplitude $A$ gives a peak of height about $A$. \ui{Log} uses a logarithmic amplitude axis, and \ui{Smooth} averages the spectra of overlapping segments of the run (Welch's method), which helps with noisy or chaotic runs at the cost of coarser frequency resolution.

\paragraph{Volterra integrals.} \XS{} supports \XPP{}'s integral terms:
\begin{itemize}
  \item \texttt{int\{K(t,t',x)\}} $=\int_0^t K(t,t',x(t'))\,dt'$, where the variables inside are evaluated at $t'$;
  \item \texttt{int\{K\#x\}} $=\int_0^t K(t-t')\,x(t')\,dt'$, a convolution with the kernel written as a function of $t$;
  \item \texttt{int[mu]\{\ldots\}} adds the weakly singular factor $(t-t')^{-\mu}$, $0\le\mu<1$;
  \item \texttt{u(t)=\ldots} or \texttt{volterra u=\ldots} defines a variable by an integral equation.
\end{itemize}
The \ui{Logistic growth with distributed delay} example is
\begin{lstlisting}
x'=r*x*(1-int{t*exp(-t/tau)/tau^2#x})
par r=1,tau=2.5
@ total=200,dt=0.05,vmaxpts=1000
\end{lstlisting}
The kernel $K(s)=s\,e^{-s/\tau}/\tau^2$ has mean delay $2\tau$. Linearising about $x=1$ gives $\lambda(1+\lambda\tau)^2+r=0$, so the equilibrium loses stability in a Hopf bifurcation at $r\tau=2$. Sweeping $\tau$ with \ui{Sweep max/min} shows the oscillation appear.

Integro-differential equations are solved by a fixed-step method: the trapezoid rule for the differential part and product-trapezoid quadrature \cite{linz1985} for the integrals. The quadrature weights are exact for the $(t-t')^{-\mu}$ factor, and the implicit terms are found by fixed-point iteration. The error falls as $dt^2$, or as $dt^{2-\mu}$ with a singular kernel. The method reproduces $u(t)=e^t$ for $u=1+\int_0^t u$, and the solution $e^{\pi t}\operatorname{erfc}(\sqrt{\pi t})$ of the Abel equation \texttt{u(t)=1-int[.5]\{1\#u\}}. It also agrees with the equivalent three-variable ODE for the gamma kernel. Only the last \texttt{vmaxpts} steps are remembered (default 4000). Because the state of such a system is its whole history, equilibria, nullclines and continuation are switched off for these models. Trajectories and sweeps work normally.

\paragraph{Periodic variables and tables.} Two further \XPP{} features are worth knowing:
\begin{itemize}
  \item \texttt{@ fold=th} keeps an angle in $[0,2\pi)$ (or $[0,\texttt{tor\_per})$). Plots break the trajectory where it wraps, and continuation measures distances modulo the period; see the \ui{Driven pendulum} example.
  \item Tables (\ui{Phase oscillators with a tabulated H}) are interpolated linearly. They can be sampled from an expression or read from a data file.
\end{itemize}

  \caption{Hutchinson's delayed logistic equation with $r=1.8$. Left: $x(t-\tau)$ against $x(t)$ for $\tau=1$, starting from the history $0.5+0.2\cos 3t$ and settling onto a periodic orbit. Right: bifurcation diagram in $\tau$. The equilibrium $x=1$ (black) loses stability at the Hopf point HB1, $\tau\approx0.874$, close to the exact value $\pi/(2r)=0.873$.   \label{fig:hutch}
\end{figure}

A delay-differential equation uses past values of its variables. In \XS{}, as in \XPP{}, \texttt{delay(x,tau)} stands for $x(t-\tau)$, where \texttt{x} must be a variable with an equation and \texttt{tau} is any expression; it may depend on the state. Load \ui{Delayed logistic equation}, Hutchinson's model \cite{hutchinson1948}:
\begin{lstlisting}
x'=r*x*(1-delay(x,tau))
aux xlag=delay(x,tau)
par r=1.8,tau=1
x(0)=0.5+0.2*cos(3*t)
\end{lstlisting}

\paragraph{History.} A delay equation needs its state on a whole interval $[-\tau,0]$, not only at $t=0$. Writing \texttt{x(0)} as a formula in \texttt{t} gives that history, and its value at $t=0$ becomes the initial condition. Without a formula, the history is held constant at the initial value. The formulas also appear in the \ui{Initial} tab under \ui{History for t < 0} (Figure~\ref{fig:history}), where they can be changed or cleared. Clicking the phase plane changes only the values at $t=0$. The auxiliary variable \texttt{xlag} makes $x(t-\tau)$ available for plotting, so the phase plane in Figure~\ref{fig:hutch} shows $x(t-\tau)$ against $x(t)$, a common way to draw the attractor of a scalar delay equation.

\begin{figure}[!htbp]
  \centering
  \includegraphics[width=0.5\textwidth]{ui-history.png}
  \caption{The Initial tab for a delay equation: the value at $t=0$ and, below it, the history for $t<0$ as a formula in $t$.}
  \label{fig:history}
\end{figure}

\paragraph{Integration.} Delay equations run forward from $t=0$ with fixed-step fourth-order Runge--Kutta (adaptive methods fall back to it). Every step is stored, and delayed values are found by cubic Hermite interpolation of the stored solution, or from the history when $t-\tau<0$. For $x'=-x(t-1)$ with $x=1$ on $[-1,0]$, whose exact solution is piecewise polynomial, the computed $x(2)$ and $x(3)$ agree with the exact values to rounding error.

\paragraph{Stability and continuation.} Equilibria of a delay equation are those of the system with the delays removed, but their stability is not. It is set by the roots of the characteristic equation
\[
\det\Bigl(\lambda I-A_0-\sum_k B_k\,e^{-\lambda\tau_k}\Bigr)=0,
\]
where $A_0$ and $B_k$ are the derivatives with respect to the current and the delayed values. There are infinitely many roots, but only finitely many lie to the right of any vertical line. \XS{} approximates the rightmost ones by Chebyshev collocation of the solution operator \cite{breda2005} and then polishes them with Newton's method. The equilibrium list then reports, for example, \emph{Unstable, 2 roots with Re $\lambda>0$} and lists the rightmost roots. \ui{Continue equilibria} uses the same roots, so Hopf points are those of the delay equation.

\begin{tryit}
\begin{enumerate}
  \item Load \ui{Delayed logistic equation} and press \key{G}. With $r\tau=1.8>\pi/2$ the solution settles onto a periodic orbit (Figure~\ref{fig:hutch}, left). Change the history formula in the Initial tab and integrate again.
  \item The inspector lists two equilibria. $x=0$ has the single root $\lambda=r$. $x=1$ has a complex pair $\lambda\approx0.097\pm1.63i$ in the right half-plane.
  \item In the Bifurcation view choose \texttt{tau}, a range of $0.2$ to $1.5$ and \ui{Step ds} $0.02$, then press \ui{Continue equilibria}. A Hopf point HB1 is found at $\tau\approx0.874$, against $\pi/(2r)=0.8727$. \ui{Sweep max/min} adds the oscillation amplitude (Figure~\ref{fig:hutch}, right).
  \item Load \ui{Mackey--Glass equation} \cite{mackey1977} (Figure~\ref{fig:mg}). With $\tau=17$ the solution is chaotic; the file uses \texttt{@ trans=300} to drop the transient. Continuation in $\tau$ finds Hopf points at $\tau\approx4.71$ and $20.98$. Linearising by hand gives $\lambda=-0.1-0.4\,e^{-\lambda\tau}$, with Hopf points at $\tau=4.708$ and $20.93$.
\end{enumerate}
\end{tryit}

\begin{figure}[!htbp]
  \centering
  \includegraphics[width=0.5\textwidth]{mg-pp.pdf}
  \caption{The chaotic Mackey--Glass attractor at $\tau=17$, drawn as $x(t)$ against $x(t-\tau)$ after a transient of 300.}
  \label{fig:mg}
\end{figure}

\noindent Periodic-orbit and two-parameter continuation, the direction field and the derivative readout are switched off for delay equations, because the state at time $t$ is a whole function rather than a point.

\section{Tutorial 10: events and global flags}\label{sec:flags}

\begin{figure}[!htbp]
  \centering
  \begin{minipage}[t]{0.48\textwidth}\centering
    \includegraphics[width=\textwidth]{ball-pp.pdf}
  \end{minipage}\hfill
  \begin{minipage}[t]{0.48\textwidth}\centering
    \includegraphics[width=\textwidth]{ball-tc.pdf}
  \end{minipage}
  \caption{The bouncing ball. Left: velocity against height. Each parabola is one flight, and the line breaks at each event instead of joining the points before and after it. Right: height $x$ (blue) and velocity $v$ (red) against time, with the jump in $v$ at each bounce.}
  \label{fig:ball}
\end{figure}

Many models change discontinuously when a threshold is reached: a neuron fires and resets, a ball bounces, a switch flips. \XPP{} describes such events with \emph{global flags},
\begin{lstlisting}
global sign condition {name1=expr1;name2=expr2;...}
\end{lstlisting}
The assignments are made when \texttt{condition} crosses zero from negative to positive (\texttt{sign}$=1$), from positive to negative ($-1$), or in either direction (0). All the right-hand sides are evaluated first, then all the assignments are made together. The names may be state or Markov variables, and \texttt{arret=1} stops the integration.

\paragraph{How events are located.} After every step \XS{} checks each condition. If one has crossed zero in its direction, the crossing time is found on the cubic Hermite interpolant of that step, by regula falsi on the condition. The point just before the event and the point just after the assignments are both stored, at the same time, and integration continues from there. This works with every integrator, including the adaptive and stiff ones, and with maps, where the assignments are applied to the new iterate.

\begin{tryit}
\begin{enumerate}
  \item Load \ui{Bouncing ball}:
\begin{lstlisting}
x'=v
v'=-g
global -1 x {x=0;v=-e*v}
\end{lstlisting}
  Press \key{G}. The status line reports the number of events. The first two bounces occur at $t=\sqrt{2x_0/g}=0.6386$ and $t=0.6386\,(1+2e)=1.7242$, and the computed times agree to six decimal places. Each flight is a parabola in the phase plane (Figure~\ref{fig:ball}). Lower the restitution $e$ with its slider and watch the bounces die away faster.
  \item Load \ui{Integrate-and-fire neuron}:
\begin{lstlisting}
v'=(-v+i-w)/tau
w'=-w/tauw
global 1 v-1 {v=0;w=w+b}
\end{lstlisting}
  Each time $v$ reaches threshold it is reset and the adaptation variable $w$ is kicked up, so the firing rate slows until it settles (Figure~\ref{fig:lif}). With $b=0$ the interspike interval is $\tau\ln\bigl(i/(i-1)\bigr)$, and the computed value agrees to six or more digits.
  \item Add \texttt{global 1 t-50 \{arret=1\}} to a model to stop every run at $t=50$.
\end{enumerate}
\end{tryit}

\begin{figure}[!htbp]
  \centering
  \includegraphics[width=0.55\textwidth]{lif-tc.pdf}
  \caption{Integrate-and-fire neuron with adaptation: $v$ (blue) is reset to 0 at each threshold crossing, while the adaptation current $w$ (red) builds up and lengthens the interspike interval.}
  \label{fig:lif}
\end{figure}

\noindent Equilibria, nullclines and equilibrium continuation ignore flags. Periodic-orbit continuation is switched off for models with flags; use \ui{Sweep max/min} for the long-term behaviour instead.

\section{Tutorial 11: boundary value problems}\label{sec:bvp}

\begin{figure}[!htbp]
  \centering
  \includegraphics[width=0.55\textwidth]{bratu-bif.pdf}
  \caption{Bratu's problem $u''=-\lambda e^u$, $u(0)=u(1)=0$, continued in $\lambda$ with \ui{Continue BVP}. The vertical axis is the slope $u'(0)$. The branch turns round the fold LP1 at $\lambda\approx3.5138$ onto the upper solutions.}
  \label{fig:bratu}
\end{figure}

\XS{} also solves two-point boundary value problems by shooting, using \XPP{}'s syntax. A line \texttt{b} (or \texttt{bndry}) followed by an expression gives a condition that the expression vanishes. In it, a plain name \texttt{u} is the value at the left end and \texttt{u'} the value at the right end. The interval runs from \texttt{t0} (\texttt{@ t0=}, default 0) to \texttt{t0} plus the total time. An unknown parameter, such as an eigenvalue, is written as a variable with zero derivative, \texttt{lam'=0}, so that the numbers of unknowns and conditions match. \texttt{\#@irange u lo hi} gives the initial value of \texttt{u} a slider in the Initial tab.

\begin{tryit}
\begin{enumerate}
  \item Load \ui{Bratu boundary value problem}:
\begin{lstlisting}
u'=up
up'=-lam*exp(u)
b u
b u'
\end{lstlisting}
  Turn on \ui{Solve BVP} above the plot. Newton's method adjusts the initial values until both conditions hold, and the status line reports the largest residual. Moving the $\lambda$ slider solves the problem again at each new value.
  \item In the Bifurcation view set the range of $\lambda$ to 0--4, choose \ui{Plot} \texttt{up}, and press \ui{Continue BVP}. Pseudo-arclength continuation in the initial values and $\lambda$ follows the branch round the fold at $\lambda\approx3.5138$ (Figure~\ref{fig:bratu}). Clicking the branch loads that solution.
  \item The examples \ui{Eigenvalue boundary value problem} and \ui{Rotating spiral wave} have a free parameter written as a variable with zero derivative. The spiral-wave example also starts at $t_0=0.01$ to avoid a singular end point.
\end{enumerate}
\end{tryit}

\section{Tutorial 13: a forced oscillator and Arnold tongues}\label{sec:torus}

\begin{figure}[!htbp]
  \centering
  \begin{minipage}[t]{0.48\textwidth}\centering
    \includegraphics[width=\textwidth]{torus-locked.pdf}
  \end{minipage}\hfill
  \begin{minipage}[t]{0.48\textwidth}\centering
    \includegraphics[width=\textwidth]{torus-unlocked.pdf}
  \end{minipage}
  \caption{The forced phase oscillator on the torus, $x$ against $y$ (both reduced modulo $2\pi$, so the lines break where they wrap). Left: $\omega=2$, inside the 1:2 tongue; the trajectories from several starts all close in on the same band, the locked orbit. Right: $\omega=2.3$, outside the tongue; the lines do not settle onto a closed orbit.}
  \label{fig:torus}
\end{figure}

In a periodically forced oscillator, or in a phase model, the state lives on a torus. The \ui{Forced phase oscillator} example has two phases, $x$ for the oscillator and $y=\omega t$ for the forcing:
\begin{lstlisting}
p(x)=-sin(x)/(1+a*cos(x))
x'=1+b*p(x)*cos(y)
y'=om
par om=2,b=.25,a=.25
@ fold=x,fold=y,tor_per=6.283185
\end{lstlisting}
Both variables are declared periodic with \texttt{@ fold=}. Plots break where they wrap, and the closing condition of a periodic orbit is taken modulo the period. A locked solution closes in that sense: $x(T)=x(0)+2\pi n$ and $y(T)=y(0)+2\pi m$ with $T=2\pi m/\omega$. Such orbits are followed by the same continuation as limit cycles. The set of parameters for which a locked solution exists is an \emph{Arnold tongue}, and its two edges are folds of cycles.

\begin{tryit}
\begin{enumerate}
  \item Load \ui{Forced phase oscillator} and press \key{G} with $\omega=2$. The trajectory settles onto a locked orbit in which $x$ goes once round while the forcing goes twice (Figure~\ref{fig:torus}, left). Change $\omega$ to $2.3$ and integrate again to see that it is no longer locked.
  \item Return to $\omega=2$, integrate, and open the Bifurcation view. Set the range of \texttt{om} to 1.2--3 and press \ui{Limit cycle}. The locked orbit exists only for $\omega$ between $1.9784$ and $2.0416$: there are two folds of cycles, LPC1 and LPC2, the edges of the 1:2 tongue. The stable and the unstable locked orbit meet at the two folds, so the branch is a closed loop. The continuation stops when it has gone once round, and the status line says that the branch closed up on itself.
  \item Open the Two-parameter view, set the range of \texttt{b} to 0--0.5, and press \ui{Follow} on LPC1 and on LPC2 in the Special points table. The two curves are the edges of the tongue in $(\omega,b)$, and they meet at $b=0$, $\omega=2$.
  \item To add the 1:1 tongue, press \ui{Clear diagram} in the Bifurcation view. This erases the one-parameter branch and leaves the two-parameter curves. Set $\omega=1$, integrate, set the range of \texttt{om} to 0.5--3, continue in \texttt{om} with \ui{Limit cycle} (the folds are at $1.1233$ and $0.8684$), and follow both folds. Turn on \ui{Legend} and \ui{Colours} (Figure~\ref{fig:tongues}).
\end{enumerate}
\end{tryit}

\begin{figure}[!htbp]
  \centering
  \includegraphics[width=0.78\textwidth]{tongues.pdf}
  \caption{The 1:1 and 1:2 Arnold tongues of the forced phase oscillator in $(\omega,b)$, as curves of folds of cycles. Each tongue has two edges, and the legend says which fold and which value of $\omega$ each curve was started from. The dashed lines mark the current parameter values.}
  \label{fig:tongues}
\end{figure}

\noindent The tongue is the region between the two edges, widening as the forcing $b$ grows. Narrower tongues, such as 1:3, are harder to reach: at $\omega=3$ the default run does not settle onto a locked orbit, so you need a longer integration or a starting point on the orbit. One-parameter diagrams add up in the same way: continuing the orbit in $\omega$ at three values of $b$ keeps three branches on the same axes, and \ui{Legend} tells them apart by the value of $b$.

\section{Tutorial 14: homoclinic and heteroclinic orbits}\label{sec:conn}

\begin{figure}[!htbp]
  \centering
  \begin{minipage}[t]{0.48\textwidth}\centering
    \includegraphics[width=\textwidth]{nagumo-front.pdf}
  \end{minipage}\hfill
  \begin{minipage}[t]{0.48\textwidth}\centering
    \includegraphics[width=\textwidth]{nagumo-curve.pdf}
  \end{minipage}
  \caption{The Nagumo front. Left: the heteroclinic orbit in the $(u,v)$ plane, from the saddle at $u=1$ to the saddle at $u=0$ (squares), with the focus at $u=a$ (dot). Right: the speed $c$ at which it exists, followed in $a$ from 0.05 to 0.45. The points lie on the exact line $c=(1-2a)/\sqrt2$ to about $10^{-9}$.}
  \label{fig:nagumo}
\end{figure}

A \emph{homoclinic orbit} leaves a saddle and comes back to it; a \emph{heteroclinic orbit} joins two saddles. Both exist only for special values of a parameter: they are codimension one, so a one-parameter diagram shows them as single points where a family of orbits ends. They matter for waves. Written in a frame moving with speed $c$, a travelling front of a reaction--diffusion equation is a heteroclinic orbit of an ordinary differential equation between two rest states, and a pulse is a homoclinic orbit. The speed $c$ is the parameter that has to be tuned until the connection exists.

\paragraph{How the orbit is found.} The orbit starts a small distance from the first saddle, along the eigenvector of its single unstable eigenvalue, and is integrated until it comes closest to the second. There the program measures on which side of the second saddle's stable manifold it passes, using the unstable eigenvector of the second saddle. The measure changes sign at a connection. \XS{} scans the range of the continuation parameter for a sign change, narrows it down by false position (the Illinois variant, which needs far fewer integrations than bisection), and accepts the result only if the orbit really goes on to the target. \ui{Follow} then steps a second parameter and solves again for the first near the previous value, in both directions.

\paragraph{The controls} are in the section \ui{Homoclinic and heteroclinic orbits} of the Bifurcation panel, under the continuation buttons. The menus \ui{From} and \ui{To} list the equilibria found in the phase plane at the current parameters, and any saddle found at the end of a branch of periodic orbits (below). \ui{Find} searches the range of the continuation parameter. The orbit found is drawn in the phase plane and becomes a point of the diagram, HOM1, HET1, \ldots{} in the table of special points. On the diagram it is marked by diamonds at the maximum and minimum of the plotted variable along the orbit, at its $L^2$ norm in the L2 view (for a homoclinic orbit, the norm of the saddle, the limit of the norms of periodic orbits that approach it), at zero frequency, and by a dashed line in the period view, where the period is infinite. Clicking its row moves to it and draws it again. \ui{Follow} in its row continues it in Parameter~2 of the Two-parameter view, over the range set there; the curve is drawn in the Two-parameter view in its own colour, and HOM1 and HET1 also appear under \ui{Start} there.

\paragraph{When to run time backwards.} The method needs the starting saddle to have exactly one real unstable direction, and the target saddle too, with all the other directions stable. If instead the starting saddle has a one-dimensional \emph{stable} manifold and a bigger unstable one, as can happen at the rest state of a pulse, tick \ui{Run time backwards}. The orbit is then followed from \ui{To} back to \ui{From}, which turns the one-dimensional stable manifold into the starting direction.

\paragraph{Limits.}
\begin{itemize}
  \item Both equilibria must be saddles with one real unstable direction (counted backwards in time if \ui{Run time backwards} is ticked). Saddles with complex unstable eigenvalues, or with a two-dimensional unstable manifold at both ends, are not handled.
  \item \ui{Follow} steps Parameter~2 and solves for Parameter~1, so a curve that turns back in Parameter~2 is lost at the turn. The status line says whether the curve ended at the edge of a range or because the connection was lost.
  \item The method has been tested on planar problems, where the answers above are exact or checked. For systems with three or more variables, check an orbit by integrating it, and do not rely on a failure to find one as proof that none exists: the range of Parameter~1 and the choice of equilibria matter.
  \item The orbit is not tested for stability, and codimension-two points are not located on the curve. Orbits found are not saved in the \texttt{.ode} file, but a script can find them again with \texttt{connect} and follow them with \texttt{follow} (Section~\ref{sec:script}).
  \item The saddle at the end of a branch is only looked for when the period is still rising over the last few orbits and has at least doubled along the branch. If the branch stopped for another reason first (the point limit, say), raise the limit and continue again, or choose the saddle by hand.
\end{itemize}

\section{Numerical settings}\label{sec:numerics}

\begin{figure}[!htbp]
  \centering
  \includegraphics[width=0.42\textwidth]{ui-numerics.png}
  \caption{The Numerics tab: integration settings at the top, continuation settings below, and the continuation tolerances (Section~\ref{sec:numerics}) further down.}
  \label{fig:numerics}
\end{figure}

The \ui{Numerics} tab (Figure~\ref{fig:numerics}) collects the integration and continuation parameters. Changes to the integration settings rerun every trajectory on screen.

\paragraph{Integration.}
\begin{description}[font=\sffamily\bfseries]
  \item[Method] As in Section~\ref{sec:language}.
  \item[Total time] The duration of each run; for maps, the number of iterations.
  \item[Transient] As in \XPP{}, the run still lasts the total time, but only $t\ge$ the transient is kept (\texttt{@ trans=}). Use it to look at attractors without the approach to them. Manifolds and the single periods loaded from continuation are never cut.
  \item[dt] The step for fixed-step methods, and the largest step for adaptive ones.
  \item[Tolerance] Applies to the adaptive methods.
  \item[Bound] Integration stops when any variable exceeds this value.
  \item[Direction] Forward, backward or both ways in time (also next to \ui{Integrate} in the Initial tab).
  \item[Start time] The start time $t_0$ of each run (\texttt{@ t0=}).
  \item[Nullcline grid] Sets the resolution of the nullclines.
  \item[Sweep samples] Sets the number of parameter values in \ui{Sweep max/min}.
\end{description}

\paragraph{Continuation.} These settings correspond to the entries of \XPP{}'s \textsf{AUTO} numerics window and can be set in the file with \texttt{@ ds, dsmin, dsmax, nmax, ntst, parmin, parmax}. Leave a box empty to use the automatic choice.
\begin{center}\small
\begin{tabularx}{0.95\textwidth}{@{}lX@{}}
\toprule
Setting & Effect\\
\midrule
Ds & initial arclength step for equilibrium branches (same as \ui{Step ds})\\
Dsmin, Dsmax & smallest and largest steps; a branch stops if the step falls below Dsmin\\
Nmax & maximum number of points in each direction of an equilibrium branch\\
Ntst (orbits) & number of shooting intervals per periodic orbit (automatic: 20 for up to 3 variables, 14 up to 5, otherwise 10)\\
Ds, Dsmax, Nmax (orbits) & the same for periodic-orbit branches and curves of cycles\\
Nmax (2-par), Nmax (2-par cycles) & point limits for two-parameter curves\\
\bottomrule
\end{tabularx}
\end{center}
\paragraph{Continuation tolerances.} Each step of a continuation predicts the next point along the tangent and corrects it with Newton's method. The correction stops when its size falls below a tolerance, and the point is then accepted only if the equations hold to within the residual tolerance; otherwise the step is halved. The section \ui{Continuation tolerances} of the Numerics tab sets these, and \ui{Defaults} puts them back. The file can set them with \texttt{@ eqtol, potol, tptol, restol, itmax, tgrow}, and \ui{Write state} writes those that differ from the defaults.
\begin{center}\small
\begin{tabularx}{0.95\textwidth}{@{}llX@{}}
\toprule
Setting & Default & Effect\\
\midrule
Newton tol (eq.) & $10^{-10}$ & last Newton correction for branches of equilibria and fixed points, relative to the size of the solution (\texttt{eqtol}, like \textsf{AUTO}'s EPSU)\\
Newton tol (orbits) & $10^{-9}$ & the same for periodic orbits, in the scaled unknowns of the shooting method (\texttt{potol})\\
Newton tol (2-par) & $10^{-8}$ & the same for two-parameter curves of folds, Hopf points and bifurcations of cycles (\texttt{tptol})\\
Residual tol & $10^{-6}$ & largest residual of the equations at an accepted point; for orbits, relative to their size (\texttt{restol})\\
Newton iterations & automatic & most Newton iterations per step before the step is halved: 15 for equilibria, 14 for orbits and two-parameter curves, 12 for curves of cycles (\texttt{itmax}, like \textsf{AUTO}'s ITNW)\\
Period growth stop & 40 & a branch of periodic orbits, or a curve of cycles, stops when the period reaches this multiple of its starting value (\texttt{tgrow})\\
\bottomrule
\end{tabularx}
\end{center}
Tighter tolerances give more accurate points and usually smaller steps; looser ones can carry a branch through a stretch where the corrector struggles, at some cost in accuracy, so check such a branch against a tighter run. Raise the period growth stop to follow orbits closer to a homoclinic orbit.

If a branch stops early, the status line says why: for example, it reached the point limit, the corrector stopped converging, the orbit shrank onto a Hopf point, or the period grew without bound (a homoclinic orbit is near). If it stopped because of a step-size or point limit, adjust the corresponding setting and run it again. A branch of orbits whose period grew to its end also loads the saddle it approaches into the homoclinic search (Section~\ref{sec:conn}).

\section{Saving and exporting results}\label{sec:export}

\begin{description}[font=\sffamily\bfseries]
  \item[Export SVG] Saves the current view as a vector figure with light-theme colours, ready for a paper or for editing in Inkscape or Illustrator. Legends and notes are included. All the plots in this document were made this way.
  \item[Export CSV] Available in the Time course, Bifurcation and Two-parameter views.
  \begin{itemize}
    \item The time-course table has every trajectory on screen, one row per stored point, with the trajectory number, its kind (trajectory or manifold), its direction (forward or backward), $t$ and every variable.
    \item The bifurcation table has one row per computed point, with these columns: curve, kind (equilibrium, periodic orbit, sweep or special), label (HB1, LPC2, \ldots), parameter name and value, stability, number of unstable directions, period, the state, and the maximum and minimum of each variable along an orbit.
    \item The two-parameter table has the two parameter values, the period where relevant, the state, and labelled rows for codimension-two points. Hopf curves also get columns for $\ell_1$ and for criticality (subcritical, supercritical or neutral saddle).
    \item In the bifurcation table, special rows for Hopf points give $\ell_1$, and the stability column says subcritical or supercritical.
  \end{itemize}
  \item[Export .dat] In the Bifurcation and Two-parameter views, saves the same continuation data as \texttt{.dat} files: numbers only, no header and space-separated columns, the form \XPP{} and gnuplot read. The bifurcation diagram gives one file each for equilibria, periodic orbits and sweeps. The status line lists the columns, and text fields become numeric codes.
  \item[Copy CSV, Save .dat] In the trajectory list, copy the current trajectory (time, variables and auxiliaries) to the clipboard, or save it as a \texttt{.dat} file.
  \item[Copy text] Copies the \texttt{.ode} file, including any edits, so that it can be saved or used in \XPP{}.
\end{description}

\subsection*{Writing the current state into the file}\label{sec:writestate}
After exploring a model you will often want to keep the parameter values and settings you have arrived at. \ui{Write state}, in the Equations tab, writes them into the \texttt{.ode} text, much as \XPP{} does when it saves a file:
\begin{itemize}
  \item parameter values and initial conditions are changed where they are defined, in the \texttt{par}, \texttt{init} and \texttt{x(0)=} lines, as are slider ranges in \texttt{\#@range} lines and history formulas of delay equations;
  \item the integration settings (method, total time, step, transient, tolerance, bound, random seed), the plot axes and window, and the continuation settings are collected in \texttt{@} lines just before \texttt{done}.
\end{itemize}
For example, after setting $i=150$ and a transient of 100 in the Morris--Lecar example, the end of the file reads
\begin{lstlisting}
param i=150,c=20
...
# Settings written by XPP Studio, 2026-10-20 10:30
@ meth=rungekutta, total=400, dt=0.25, trans=100, bound=10000
@ xp=v, yp=w, zp=ica, xlo=-75, xhi=45, ylo=-0.1, yhi=0.55
@ ds=2, nmax=3000, parmin=0, parmax=300
done
\end{lstlisting}
Pressing \ui{Write state} again replaces this block rather than adding another, and \ui{Apply} on the result restores exactly the same state. The text is not reloaded, so the trajectories on screen are kept. Use \ui{Copy text}, or your browser's own storage of the editor, to keep the file. Parameters defined through array lines are left as written.

\section{Differences from \XPP{}}

\XS{} aims to read the same files and to feel familiar, but it is a reimplementation:
\begin{itemize}
  \item \textbf{Continuation.} It is built in and written from scratch: pseudo-arclength continuation of equilibria, and multiple shooting (rather than \textsf{AUTO}'s orthogonal collocation) for periodic orbits. Results agree with \textsf{AUTO} to plotting accuracy on the examples, but very long or very unstable orbits may need more shooting intervals (Ntst).
  \item \textbf{Delay equations} are integrated with a fixed step only, and periodic orbits of delay equations cannot be continued. \XPP{}'s other delay options, such as \texttt{delshft} and \texttt{ndelay}, are not supported. The \texttt{@ delay} option is accepted but not needed, since all of the history is kept.
  \item \textbf{Global flags} can set state and Markov variables and \texttt{arret}. The XPP output flag \texttt{out\_put} is accepted and ignored.
  \item \textbf{Not supported:} \texttt{special} and \texttt{export} declarations, and \texttt{set} blocks.
  \item \textbf{Two-parameter Hopf curves} are limited to 12 variables, because the bialternate product grows quadratically with dimension.
  \item \textbf{Homoclinic and heteroclinic orbits} (Section~\ref{sec:conn}) are found by shooting along the one-dimensional unstable manifold of a saddle, not by \textsf{AUTO}'s \textsf{HomCont} projection boundary conditions, so they are limited to saddles with one real unstable direction (or one real stable direction, with time running backwards).
  \item \textbf{Volterra models} cannot be continued, since their state is infinite-dimensional.
  \item \textbf{Browser files.} Files are opened and saved through the browser. Table data files are kept in the browser's local storage until you press \ui{Forget table files}.
\end{itemize}
