\begin{abstract}
\noindent \XS{} is a browser-based environment for exploring dynamical systems, modelled on Bard Ermentrout's \XPP{}. It reads \XPP{}'s \texttt{.ode} files and provides phase planes, three-dimensional views, time courses, numerical continuation of equilibria and periodic orbits, one- and two-parameter bifurcation diagrams, maps, stochastic and Markov models, stiff solvers, delay equations, events (global flags), boundary value problems, arrays and Volterra integral equations, and computes the phase and isostable reduction of limit cycles for weakly coupled oscillators. Everything runs locally in a web page: there is nothing to install and no data leaves the browser. This document introduces the interface, describes the model language, and works through a sequence of short tutorials using the examples that come with the program.
\end{abstract}

\section{Introduction}

\begin{notebox}
\textbf{About this version.} Features have been added since many of the screenshots and figures in this document were made, and the earlier pictures have not been remade. The text is current and the pictures may differ from the program in small ways. The new features are described in the later tutorials rather than in the tour of the interface, in particular Tutorials~13 to~15. The most visible change is a sixth view, \ui{Phase reduction} (key \key{6}), which now holds the adjoint and the interaction function of coupled oscillators; the screenshots of the interface show five views, and the Bifurcation panel in them still has the \ui{Adjoint} row, which has since moved to the new view. Tutorial~15 (Section~\ref{sec:adjoint}) replaces the earlier tutorial on the adjoint, and adds the isostable functions, the second-order theory of weakly coupled oscillators, and an example with exact answers.
\end{notebox}

For more than thirty years \XPP{} \cite{ermentrout2002} has been one of the standard tools for simulating and analysing differential equations in mathematical biology, neuroscience and applied dynamical systems. Its strengths are a compact, readable model language, fast interactive phase-plane analysis, and a tight connection to the continuation package \textsf{AUTO} \cite{doedel2007}. \XS{} keeps that model language and that way of working, and puts them in a modern interface:

\begin{itemize}
  \item \textbf{Same files.} Most \XPP{} \texttt{.ode} files load unchanged. Supported features include parameters, functions, fixed quantities, auxiliary variables, maps, Wiener noise, Markov variables, tables, periodic (folded) variables, arrays, Volterra integrals, delays, global flags and boundary conditions (Section~\ref{sec:language}).
  \item \textbf{Live analysis.} Dragging a parameter slider immediately recomputes trajectories, nullclines and equilibria. For large systems, or when you want to change several things before anything is recomputed, the \ui{Auto-update} box can be unticked (Section~\ref{sec:autorun}).
  \item \textbf{Built-in continuation.} Equilibria, periodic orbits and their bifurcations can be continued in one or two parameters without leaving the program. Detected points include folds, Hopf, period-doubling, torus, fold-of-cycles and codimension-two points.
  \item \textbf{Publication output.} Every view can be exported as a vector SVG figure. Continuation data can be exported as CSV, and trajectories copied as CSV.
\end{itemize}

\noindent The program is a single web page. To use it, open
\begin{center}
  \url{\xppurl}
\end{center}
in any recent browser. The source code, the example models and this tutorial are in the repository \url{\xppgit}. Its file \texttt{index.html} is the whole program, and it also runs when opened directly from disk.

\paragraph{How this document is organised.} Section~\ref{sec:tour} is a tour of the interface and Section~\ref{sec:language} summarises the model language. Sections~\ref{sec:pp}--\ref{sec:volterra} are hands-on tutorials, each built on an example from the \ui{Model} menu. Section~\ref{sec:script} shows how to record and replay the steps behind a set of figures with a script. Sections~\ref{sec:torus}, \ref{sec:conn} and~\ref{sec:adjoint} are three further tutorials, on a forced oscillator, on homoclinic and heteroclinic orbits, and on phase reduction and weakly coupled oscillators. Section~\ref{sec:numerics} covers numerical settings and Section~\ref{sec:export} exporting results. The document ends with the differences from \XPP{} and with credits.

The window (Figure~\ref{fig:overview}) has three columns.

\paragraph{Left: the model.} Five tabs:
\begin{description}[font=\sffamily\bfseries]
  \item[Equations] The \texttt{.ode} text, which you can edit freely. \ui{Apply} (or \key{Ctrl}+\key{Enter}) reloads the model, and messages underneath report what was loaded and any errors, with line numbers. \ui{Open .ode} loads a file from disk, \ui{Copy text} copies the current text, \ui{Write state} writes the current parameters, initial conditions and settings into it (Section~\ref{sec:writestate}), and \ui{Table files} supplies data files used by \texttt{table} declarations. \ui{Reset all}, under the messages, puts \XS{} back as it is the first time it is opened: the default model (Morris--Lecar), view and settings, with no trajectories, diagrams or labels. It also forgets what the browser has kept between visits (your edited equations, the script, table files and display choices such as \ui{Legend}), so copy anything you want to keep first; it asks before it does anything. To go back to the values in the current file without losing the file, press \ui{Apply} instead.
  \item[Parameters] One row per parameter, with a value box and a slider whose limits you can edit. Drag a slider to see everything update live (unless \ui{Auto-update} is unticked, see below), and use \ui{Reset} to restore the values in the file. The up and down arrows on a value box, and the arrow keys on a slider, change the value by 1\% of the slider's range (10\% with \key{Shift}).
  \item[Initial] Initial values of the state variables (and Markov states). \ui{Integrate} runs from here, and \ui{Last point $\to$ IC} copies the end of the current trajectory into the initial conditions.
  \item[Numerics] Integration method, total time, transient, step size, tolerance and bound, plus the continuation settings (Section~\ref{sec:numerics}).
  \item[Script] A list of commands that drives the interface, to make a set of figures again exactly, with one click (Section~\ref{sec:script}).
\end{description}

\paragraph{Centre: the plot.} Six views, chosen with the buttons above the plot or with the keys \key{1}--\key{6}:
\begin{description}[font=\sffamily\bfseries]
  \item[Phase plane] Any two variables (state, Markov, Volterra or auxiliary) against each other, with optional nullclines, direction field and equilibria. Nullclines are on when a planar system of differential equations is loaded, and off otherwise: in higher dimensions they are slices through the current values of the other variables, slower to draw and seldom what is wanted. Press \key{N} to show them. For a one-dimensional map this view shows a cobweb diagram. \ui{Equal axes} gives both axes the same scale. \ui{Run grid} in the Initial tab starts trajectories from a grid of points, by default covering the window (Section~\ref{sec:many}). Below the plane a strip shows the time series of the current trajectory.
  \item[3D] Three variables (or time) in a rotatable box: drag to rotate, scroll to zoom, \ui{Spin} to animate. \ui{Equilibria} shows or hides the equilibria; while they are hidden, the box fits the trajectories alone.
  \item[Time course] Chosen variables against $t$ (or the iteration number $n$ for maps). \ui{Spectrum} shows their power spectra instead, and \ui{Space-time} shows a row of indexed variables as an image (Section~\ref{sec:spacetime}).
  \item[Bifurcation] Branches of equilibria and periodic orbits, parameter sweeps, and homoclinic and heteroclinic orbits, against one parameter. The vertical axis is a variable, or the period or frequency of the periodic orbits.
  \item[Two-parameter] Curves of folds, Hopf points, period doublings and bifurcations of cycles in a parameter plane.
  \item[Phase reduction] The phase response (adjoint) of periodic orbits, the isostable response and Floquet eigenfunction of their slowest multiplier, and the interaction functions of two weakly coupled copies, to first and second order (Section~\ref{sec:adjoint}). Its controls are in the right-hand panel.
\end{description}
\paragraph{Across the top,} next to the model's title, are three controls that decide when things are computed and which values are used. \ui{Auto-update} is a tick box: while it is ticked, changing a parameter, an initial value or a numerical setting runs the trajectories again at once. When it is unticked, \ui{Run} brings the display up to date on demand. \ui{Sets} appears only when the file defines any, and applies a named collection of parameters, initial values and settings in one step (Section~\ref{sec:sets}). Section~\ref{sec:autorun} describes Auto-update and the handling of long computations.

\paragraph{The status line} at the bottom of the window reports what the last action did: how many points a trajectory has, why a branch stopped, where a special point was found. \ui{History}, at its right-hand end, lists every message since the page was opened, each with its time, so that a report that has scrolled away can be read again. Progress reports during a long computation are kept as one line, the last one. \ui{Download} saves the list as a text file, \ui{Copy} copies it and \ui{Clear} empties it; in a script, \texttt{history save} does the same (Section~\ref{sec:script}).

In every view you drag to pan and scroll to zoom. \ui{Fit} rescales to the data, and \ui{Window} sets the axis limits by hand (they then stay fixed until you press \ui{Fit}). \ui{Points} draws trajectories as dots instead of lines, which is the default for maps. \ui{Export SVG} saves the current view as a vector figure. \ui{Export CSV} saves the data behind the time course, bifurcation diagram or two-parameter diagram, and \ui{Export DAT} saves continuation data as plain columns of numbers (Section~\ref{sec:export}).

\paragraph{Labelling a plot.}\label{sec:notes} The \ui{Add label} chip above the plot puts a text label on the figure. It appears in the phase plane, the time course (including the spectrum and the space-time plot), the Bifurcation view and the two-parameter plane, but not in the 3D views. Press it, click the plot where the label should go, and type the text in the small box that opens; a new line in the box starts a new line of text. The box also sets the size (small, medium or large) and the colour: the ordinary text colour, the accent, one of the colours used for curves and trajectories, or any colour from the colour picker. Close the box with \ui{Done}, \key{Ctrl}+\key{Enter}, \key{Esc} or a click elsewhere; a note with no text is discarded.
\begin{itemize}
  \item \textbf{Move, edit, delete.} Drag a note to move it, double-click it to edit it, or click it to select it and press \key{Delete}. \ui{Delete} in the editing box removes it too.
  \item \textbf{Notes belong to a plot.} A note is placed in the data coordinates of the plot it was made on, so it stays on its feature when you pan and zoom. It is shown only on that plot: the phase plane of that pair of variables, the diagram for that continuation parameter and vertical axis, or that parameter plane. Switch to other axes and the note is hidden, and it comes back when you return. Loading another model removes all notes.
  \item \textbf{In figures and scripts.} Notes are drawn in \ui{Export SVG}, in the colours of the light theme, along with the legend. A note you make while recording is written into the script as a \texttt{note} line (Section~\ref{sec:script}). Notes are not saved in the \texttt{.ode} file.
\end{itemize}

\paragraph{Right: the inspector.} The inspector's contents depend on the view. In the phase plane it lists the equilibria (type, coordinates and eigenvalues, with buttons to make one the initial condition, start continuation from it, or draw its separatrices), the variables in the time course, and the trajectories. For large systems, and for boundary value problems, equilibria are not searched for automatically; \ui{Find connecting orbit} next to the list searches the visible window when you want them. In the Bifurcation view it holds the continuation controls, the search for homoclinic and heteroclinic orbits, and the table of special points. In the Two-parameter view it holds the two-parameter controls.

\section{The model language}\label{sec:language}

A model is a plain-text \texttt{.ode} file in \XPP{}'s format. Lines starting with \texttt{\#} are comments, and the first comment line becomes the model's title. Names are case-insensitive, as in \XPP{}: \texttt{V} and \texttt{v} are the same variable. A file that writes the same name with different capitals gets a warning when it is loaded, since the two were probably meant to differ. The Morris--Lecar example \cite{morris1981,rinzel1989} illustrates most of the basic syntax:

\begin{lstlisting}
# Morris-Lecar neuron, Hopf regime (Rinzel & Ermentrout)
dv/dt=(i+gl*(vl-v)+gk*w*(vk-v)+gca*minf(v)*(vca-v))/c
dw/dt=phi*(winf(v)-w)/tauw(v)
minf(v)=.5*(1+tanh((v-v1)/v2))
winf(v)=.5*(1+tanh((v-v3)/v4))
tauw(v)=1/cosh((v-v3)/(2*v4))
aux ica=gca*minf(v)*(v-vca)
param i=60,c=20
param vk=-84,vl=-60,vca=120
param gk=8,gl=2,gca=4.4
param v1=-1.2,v2=18,v3=2,v4=30,phi=.04
init v=-60,w=0.015
#@range i 0 300
@ total=400,dt=0.25,meth=rk4,xp=v,yp=w
@ xlo=-75,xhi=45,ylo=-0.1,yhi=0.55
done
\end{lstlisting}

\begin{notebox}
\textbf{Methods.} \texttt{meth=} accepts \texttt{rk4} (fixed-step Runge--Kutta), \texttt{euler}, \texttt{dp45} (adaptive Dormand--Prince 4(5)), and the stiff names \texttt{stiff}, \texttt{gear}, \texttt{cvode}, \texttt{rosenbrock} and \texttt{backeul}. All of the stiff names select an adaptive Rosenbrock 2(3) solver \cite{shampine1997}. \texttt{discrete} iterates a map. Models with Wiener variables always use Euler--Maruyama, and models with Volterra integrals use a product-trapezoid scheme.
\end{notebox}

\paragraph{Sets.}\label{sec:sets} A \emph{set} is a named collection of parameter values, initial values and numerical settings. It is written as in \XPP{}, one line for each set, with the items separated by commas or semicolons:
\begin{lstlisting}
set fast {a=4, b=2, x=0.5, total=50, dt=0.01}
set slow {a=1, b=0.5, y=0.2, total=120}
\end{lstlisting}
\noindent When a file has sets, a \ui{Sets} menu appears at the top of the window. Choosing a set changes everything it lists at once and then runs \emph{once}, rather than once for each value. With \ui{Auto-update} ticked, the current curve is started again from the new initial values and the other curves are recomputed; with it unticked, the display is marked out of date and \ui{Run} computes it. The menu returns to \ui{Sets} after each choice, so the same set can be applied again after you have edited values by hand, and the status line lists what was changed.
\begin{itemize}
  \item A set may name parameters, state variables (Markov states too) and the integration settings of the Numerics tab: \texttt{total}, \texttt{dt}, \texttt{meth}, \texttt{trans}, \texttt{bound}, \texttt{tol} and so on. Only what a set mentions changes; everything else keeps its present value, and \ui{Reset} in the Parameters tab still restores the values in the file.
  \item \XPP{} files often put the plot itself into a set (\texttt{xlo}, \texttt{xhi}, \texttt{ylo}, \texttt{yhi}, \texttt{xp}, \texttt{yp}, \texttt{zp}). These are accepted but ignored: the plot stays as you have set it. The status line names them, and any other name it does not recognise.
  \item Set names are not case-sensitive. In a script, \texttt{use fast} applies a set (Section~\ref{sec:script}).
\end{itemize}

\begin{tryit}
Add two lines before \texttt{done} in the Morris--Lecar example and press \ui{Apply}:
\begin{lstlisting}
set rest {i=60, total=400}
set firing {i=150, total=200}
\end{lstlisting}
Choose \texttt{firing} from the \ui{Sets} menu: the current curve is recomputed at $i=150$ and settles onto the limit cycle of Section~\ref{sec:pp}. Choose \texttt{rest}, and it returns to the stable focus. The slider for $i$ moves with each choice.
\end{tryit}

\section{Tutorial 1: phase-plane analysis}\label{sec:pp}

\begin{figure}[!htbp]
  \centering
  \includegraphics[width=0.75\textwidth]{ml-phaseplane.pdf}
  \caption{Morris--Lecar phase plane at $i=60$: the $v$-nullcline (orange), the $w$-nullcline (green), a stable focus (filled circle) and several trajectories. Open circles mark starting points.}
  \label{fig:mlpp}

Choose \ui{Morris--Lecar} from the \ui{Model} menu. The phase plane shows $w$ against the membrane potential $v$, together with the two nullclines.

\begin{tryit}
\begin{enumerate}
  \item Click anywhere in the plane to start a trajectory there. Shift-click integrates in both directions of time. Each new trajectory gets its own colour and appears in the \ui{Trajectories} list, where you can remove it with~$\times$.
  \item Press \key{D} for the direction field and \key{N} to hide or show the nullclines. Hovering over the plot shows the coordinates and the derivatives $v'$, $w'$ at the pointer.
  \item The inspector lists one equilibrium, a \emph{stable focus}, with its eigenvalues $\lambda\approx-0.055\pm0.063i$. \ui{Set as IC} moves the initial condition onto it.
  \item Open the \ui{Parameters} tab and slowly drag the slider for the applied current~$i$. Between about $i=94$ and $i=212$ the focus becomes unstable and trajectories settle onto a large limit cycle: repetitive firing.
  \item Press \key{3} for the time course. The chips in the inspector choose which variables are plotted, auxiliary ones included (\texttt{ica} here).
  \item To label the figure, press \ui{Add label}, click next to the stable focus and type \texttt{stable focus}. Drag the label where you want it, and choose a colour in the box if you like. Labels are explained in Section~\ref{sec:notes}.
\end{enumerate}
\end{tryit}

\noindent Equilibria are found by Newton's method from a grid of starting points covering the visible window, so panning or zooming out searches a wider region. For a saddle, the \ui{Separatrices} button integrates its stable and unstable manifolds. Once drawn, they follow the saddle: when you change a parameter, the saddle is found again and its separatrices are recomputed from its new position, so you can watch, for example, a separatrix approach a homoclinic connection as you drag a slider.

\begin{enumerate}
  \item Press \ui{Continue equilibria}. Pseudo-arclength continuation \cite{keller1977} traces the branch in both directions across the range. \begin{notebox}
\textbf{Sub- or supercritical?} At a Hopf point with eigenvalues $\pm i\omega$, \XS{} computes the first Lyapunov coefficient
\[
\ell_1=\frac{1}{2\omega}\,\mathrm{Re}\Bigl[\langle p,C(q,q,\bar q)\rangle-2\langle p,B(q,A^{-1}B(q,\bar q))\rangle+\langle p,B(\bar q,(2i\omega I-A)^{-1}B(q,q))\rangle\Bigr],
\]
where $A$ is the Jacobian, $Aq=i\omega q$, $A^{\mathsf T}p=-i\omega p$ and $\langle p,q\rangle=1$. This is the projection formula of \cite[Section~5.4, p.~180]{kuznetsov2004}. The multilinear forms $B$ and $C$ (the second and third derivatives of the vector field) are evaluated by finite differences. If $\ell_1<0$ the bifurcation is \emph{supercritical}: a small stable orbit appears on the side where the equilibrium is unstable. If $\ell_1>0$ it is \emph{subcritical}: an unstable orbit appears on the side where the equilibrium is stable, and the system usually jumps to a distant attractor.
\end{notebox}

\begin{notebox}
\textbf{What is detected.} For equilibria of flows: folds (LP), Hopf points (HB, tagged sub- or supercritical) and branch points (BP). For periodic orbits: folds of cycles (LPC), period doublings (PD) and torus (Neimark--Sacker) points (TR). For fixed points of maps: LP, PD and Neimark--Sacker (NS). At a PD of cycles, \ui{Double} switches to the period-doubled branch, and at a branch point \ui{Switch} follows the other branch through it. A branch that comes back to its starting point, such as an isola, is closed into a loop and reported as such.
\end{notebox}

\subsection*{Period doublings and orbits of higher period}
An orbit of period $N$ of a map $f$ is a fixed point of the $N$-th iterate $f^N$, and \XS{} continues it as one. Its stability comes from the multipliers of $f^N$, and a period doubling of $f^N$ is where the orbit of period $2N$ is born.

\begin{tryit}
\begin{enumerate}
  \item Load \ui{Logistic map}, open the Bifurcation view and press \ui{Continue fixed points}. The fixed point $x=1-1/r$ loses stability at PD1, $r=3$.
  \item Press \ui{Double} on PD1 in the table of special points. The orbits of period 2 are continued, and each is drawn at both of its points, so the branch splits into two. A new period doubling PD2 is found at $r\approx3.4495$, and the \ui{Period} column of the table gives the period of the orbit it creates, here 4.
  \item Press \ui{Double} on PD2, then on PD3 and PD4. The doublings come at $r\approx3.5441$ and $3.5644$, closer and closer together, with ratios of successive gaps approaching Feigenbaum's constant $4.669\ldots$ \cite{feigenbaum1978}. Press \ui{Orbit diagram} to compare with the attractor (Figure~\ref{fig:cascade}, left). Where a continued orbit is drawn dotted, it is momentarily an orbit of lower period.
  \item Orbits that are not born in a period doubling can be followed directly. Set \ui{Period} to 3 in the Continuation panel, set $r=3.84$ and $x=0.15$, and press \ui{Continue fixed points}. The period-3 window opens at a fold, LP1 at $r=1+\sqrt8\approx3.8284$, and its stable orbit doubles at $r\approx3.8415$. A starting point is found by Newton's method from the initial condition, which may land on an orbit of lower period (a fixed point, say). Tick \ui{minimal period only}, under \ui{Period}, to look only for orbits whose least period is the one asked for: \XS{} then also tries the points of the orbit through the initial condition and a grid over the phase-plane window, and draws the branch only where its orbits keep that least period (the script command is \texttt{period 3 minimal}).
  \item \ui{Follow} on a period doubling traces its curve in two parameters, for any period. In the \ui{Hénon map} example, continue the fixed point in $a$, press \ui{Double} on PD1 and PD2, set the second parameter to $b$, and follow PD1, PD2 and PD3 (Figure~\ref{fig:cascade}, right). For the fixed point the curve is $a=\tfrac34(1-b)^2$.
  \item \ui{Chirikov--Taylor map (area-preserving twist map)} is a map of the torus, $p\mapsto p+\frac{K}{2\pi}\sin q$, $q\mapsto q+p$ with the new $p$, both taken modulo $2\pi$ (\texttt{@ fold=}). Press \key{G}, then click in the phase plane to start more orbits. With the kick written as $K/2\pi$, $K=6$ is close to the value at which the last invariant circles running round the torus break up: chains of islands and chaotic layers lie side by side. Smaller $K$ (try 3) gives more invariant circles, larger $K$ (try 12) mostly chaos.
\end{enumerate}
\end{tryit}

\paragraph{Wiener noise.} Declaring \texttt{wiener w} makes \texttt{w} a white-noise source. markov s 2

\section{Tutorial 8: arrays and Volterra equations}\label{sec:volterra}

  \label{fig:arrays}

\paragraph{Arrays.} \XPP{}'s arrays are a text macro. The \ui{Chain of 20 FitzHugh--Nagumo cells} example is written as
\begin{lstlisting}
%[1..20]
v[j]'=v[j]-v[j]^3/3-w[j]+i1*heav(1.5-[j])+d*(v[j+1]-2*v[j]+v[j-1])
%
w[1..20]'=eps*(v[j]+a-b*w[j])
v0=v1
v21=v20
init v[1..20]=-1.2
init w[1..20]=-0.62
\end{lstlisting}
The block between \texttt{\%[1..20]} and \texttt{\%} is repeated for $j=1,\ldots,20$. Every \texttt{[expr]} is replaced by its integer value, so \texttt{v[j-1]} becomes \texttt{v3} when $j=4$, and \texttt{[j]} on its own becomes the number~$j$. A single line containing \texttt{[1..20]} is repeated the same way. The load message reports how many lines the file expanded to. The expanded model is an ordinary 40-dimensional system, so its equilibria, eigenvalues (computed by the QR algorithm) and continuation all work as usual. In Figure~\ref{fig:arrays} (left) the time course shows $v_1$, $v_{10}$ and $v_{20}$; choose them with the chips in the inspector.

\paragraph{Space-time plots.}\label{sec:spacetime} For a chain or lattice it is often clearer to see all the cells at once, as in \XPP{}'s array plot. In the Time course view, \ui{Space-time} draws a row of indexed variables as an image, with time across and the cell index up (Figure~\ref{fig:spacetime}). Each point is coloured by its value, and a colour bar shows the range. A \emph{row} is any set of at least six variables with a common name and consecutive numbers, such as $v_1,\ldots,v_{20}$; when a model has several rows, \ui{show} chooses between them. \ui{colour min} and \ui{max} fix the colour range, and \ui{Auto} returns to the range of the run. In the chain the travelling pulses appear as stripes, and their slope is the propagation speed.

\begin{figure}[!htbp]
  \centering
  \includegraphics[width=0.62\textwidth]{chain-spacetime.pdf}
  \caption{Space-time plot of $v_1,\ldots,v_{20}$ for the chain of FitzHugh--Nagumo cells. Each pulse starts at cell 1 and crosses the chain in about 20 time units.}
  \label{fig:spacetime}
\end{figure}

\paragraph{Spectra.} \ui{Spectrum} in the Time course view replaces the time series by the power spectrum of each chosen variable, as amplitude against frequency (cycles per unit of $t$). A sinusoid of amplitude $A$ gives a peak of height about $A$. \ui{Log} uses a logarithmic amplitude axis, and \ui{Smooth} averages the spectra of overlapping segments of the run (Welch's method), which helps with noisy or chaotic runs at the cost of coarser frequency resolution.

\paragraph{Volterra integrals.} \XS{} supports \XPP{}'s integral terms:
\begin{itemize}
  \item \texttt{int\{K(t,t',x)\}} $=\int_0^t K(t,t',x(t'))\,dt'$, where the variables inside are evaluated at $t'$;
  \item \texttt{int\{K\#x\}} $=\int_0^t K(t-t')\,x(t')\,dt'$, a convolution with the kernel written as a function of $t$;
  \item \texttt{int[mu]\{\ldots\}} adds the weakly singular factor $(t-t')^{-\mu}$, $0\le\mu<1$;
  \item \texttt{u(t)=\ldots} or \texttt{volterra u=\ldots} defines a variable by an integral equation.
\end{itemize}
The \ui{Logistic growth with distributed delay} example is
\begin{lstlisting}
x'=r*x*(1-int{t*exp(-t/tau)/tau^2#x})
par r=1,tau=2.5
@ total=200,dt=0.05,vmaxpts=1000
\end{lstlisting}
The kernel $K(s)=s\,e^{-s/\tau}/\tau^2$ has mean delay $2\tau$. Linearising about $x=1$ gives $\lambda(1+\lambda\tau)^2+r=0$, so the equilibrium loses stability in a Hopf bifurcation at $r\tau=2$. Sweeping $\tau$ with \ui{Sweep max/min} shows the oscillation appear.

Integro-differential equations are solved by a fixed-step method: the trapezoid rule for the differential part and product-trapezoid quadrature \cite{linz1985} for the integrals. The quadrature weights are exact for the $(t-t')^{-\mu}$ factor, and the implicit terms are found by fixed-point iteration. The error falls as $dt^2$, or as $dt^{2-\mu}$ with a singular kernel. The method reproduces $u(t)=e^t$ for $u=1+\int_0^t u$, and the solution $e^{\pi t}\operatorname{erfc}(\sqrt{\pi t})$ of the Abel equation \texttt{u(t)=1-int[.5]\{1\#u\}}. It also agrees with the equivalent three-variable ODE for the gamma kernel. Only the last \texttt{vmaxpts} steps are remembered (default 4000). Because the state of such a system is its whole history, equilibria, nullclines and continuation are switched off for these models. Trajectories and sweeps work normally.

\paragraph{Periodic variables and tables.} Two further \XPP{} features are worth knowing:
\begin{itemize}
  \item \texttt{@ fold=th} keeps an angle in $[0,2\pi)$ (or $[0,\texttt{tor\_per})$). Plots break the trajectory where it wraps, and continuation measures distances modulo the period; see the \ui{Driven pendulum} example.
  \item Tables (\ui{Phase oscillators with a tabulated H}) are interpolated linearly. They can be sampled from an expression or read from a data file.
\end{itemize}

\section{Tutorial 9: delay equations}\label{sec:dde}

\begin{figure}[!htbp]
  \centering
  \begin{minipage}[t]{0.48\textwidth}\centering
    \includegraphics[width=\textwidth]{hutch-pp.pdf}
  \end{minipage}\hfill
  \begin{minipage}[t]{0.48\textwidth}\centering
    \includegraphics[width=\textwidth]{hutch-bif.pdf}
  \end{minipage}
  \caption{Hutchinson's delayed logistic equation with $r=1.8$. Left: $x(t-\tau)$ against $x(t)$ for $\tau=1$, starting from the history $0.5+0.2\cos 3t$ and settling onto a periodic orbit. Right: bifurcation diagram in $\tau$. The equilibrium $x=1$ (black) loses stability at the Hopf point HB1, $\tau\approx0.874$, close to the exact value $\pi/(2r)=0.873$. The purple dots, from \ui{Sweep max/min}, show the oscillation that grows from it.}
  \label{fig:hutch}
\end{figure}

A delay-differential equation uses past values of its variables. In \XS{}, as in \XPP{}, \texttt{delay(x,tau)} stands for $x(t-\tau)$, where \texttt{x} must be a variable with an equation and \texttt{tau} is any expression; it may depend on the state. Load \ui{Delayed logistic equation}, Hutchinson's model \cite{hutchinson1948}:
\begin{lstlisting}
x'=r*x*(1-delay(x,tau))
aux xlag=delay(x,tau)
par r=1.8,tau=1
x(0)=0.5+0.2*cos(3*t)
\end{lstlisting}

\paragraph{History.} A delay equation needs its state on a whole interval $[-\tau,0]$, not only at $t=0$. Writing \texttt{x(0)} as a formula in \texttt{t} gives that history, and its value at $t=0$ becomes the initial condition. Without a formula, the history is held constant at the initial value. The formulas also appear in the \ui{Initial} tab under \ui{History for t < 0} (Figure~\ref{fig:history}), where they can be changed or cleared. Clicking the phase plane changes only the values at $t=0$. The auxiliary variable \texttt{xlag} makes $x(t-\tau)$ available for plotting, so the phase plane in Figure~\ref{fig:hutch} shows $x(t-\tau)$ against $x(t)$, a common way to draw the attractor of a scalar delay equation.

\begin{figure}[!htbp]
  \centering
  \includegraphics[width=0.5\textwidth]{ui-history.png}
  \caption{The Initial tab for a delay equation: the value at $t=0$ and, below it, the history for $t<0$ as a formula in $t$.}
  \label{fig:history}
\end{figure}

\paragraph{Integration.} Delay equations run forward from $t=0$ with fixed-step fourth-order Runge--Kutta (adaptive methods fall back to it). Every step is stored, and delayed values are found by cubic Hermite interpolation of the stored solution, or from the history when $t-\tau<0$. For $x'=-x(t-1)$ with $x=1$ on $[-1,0]$, whose exact solution is piecewise polynomial, the computed $x(2)$ and $x(3)$ agree with the exact values to rounding error.

\paragraph{Stability and continuation.} Equilibria of a delay equation are those of the system with the delays removed, but their stability is not. It is set by the roots of the characteristic equation
\[
\det\Bigl(\lambda I-A_0-\sum_k B_k\,e^{-\lambda\tau_k}\Bigr)=0,
\]
where $A_0$ and $B_k$ are the derivatives with respect to the current and the delayed values. There are infinitely many roots, but only finitely many lie to the right of any vertical line. \XS{} approximates the rightmost ones by Chebyshev collocation of the solution operator \cite{breda2005} and then polishes them with Newton's method. The equilibrium list then reports, for example, \emph{Unstable, 2 roots with Re $\lambda>0$} and lists the rightmost roots. \ui{Continue equilibria} uses the same roots, so Hopf points are those of the delay equation.

\begin{tryit}
\begin{enumerate}
  \item Load \ui{Delayed logistic equation} and press \key{G}. With $r\tau=1.8>\pi/2$ the solution settles onto a periodic orbit (Figure~\ref{fig:hutch}, left). Change the history formula in the Initial tab and integrate again.
  \item The inspector lists two equilibria. $x=0$ has the single root $\lambda=r$. $x=1$ has a complex pair $\lambda\approx0.097\pm1.63i$ in the right half-plane.
  \item In the Bifurcation view choose \texttt{tau}, a range of $0.2$ to $1.5$ and \ui{Step ds} $0.02$, then press \ui{Continue equilibria}. A Hopf point HB1 is found at $\tau\approx0.874$, against $\pi/(2r)=0.8727$. \ui{Sweep max/min} adds the oscillation amplitude (Figure~\ref{fig:hutch}, right).
  \item Load \ui{Mackey--Glass equation} \cite{mackey1977} (Figure~\ref{fig:mg}). With $\tau=17$ the solution is chaotic; the file uses \texttt{@ trans=300} to drop the transient. Continuation in $\tau$ finds Hopf points at $\tau\approx4.71$ and $20.98$. Linearising by hand gives $\lambda=-0.1-0.4\,e^{-\lambda\tau}$, with Hopf points at $\tau=4.708$ and $20.93$.
\end{enumerate}
\end{tryit}

\begin{figure}[!htbp]
  \centering
  \includegraphics[width=0.5\textwidth]{mg-pp.pdf}
  \caption{The chaotic Mackey--Glass attractor at $\tau=17$, drawn as $x(t)$ against $x(t-\tau)$ after a transient of 300.}
  \label{fig:mg}
\end{figure}

\noindent Periodic-orbit and two-parameter continuation, the direction field and the derivative readout are switched off for delay equations, because the state at time $t$ is a whole function rather than a point.

\section{Tutorial 10: events and global flags}\label{sec:flags}

\begin{figure}[!htbp]
  \centering
  \begin{minipage}[t]{0.48\textwidth}\centering
    \includegraphics[width=\textwidth]{ball-pp.pdf}
  \end{minipage}\hfill
  \begin{minipage}[t]{0.48\textwidth}\centering
    \includegraphics[width=\textwidth]{ball-tc.pdf}
  \end{minipage}
  \caption{The bouncing ball. Left: velocity against height. Each parabola is one flight, and the line breaks at each event instead of joining the points before and after it. Right: height $x$ (blue) and velocity $v$ (red) against time, with the jump in $v$ at each bounce.}
  \label{fig:ball}
\end{figure}

Many models change discontinuously when a threshold is reached: a neuron fires and resets, a ball bounces, a switch flips. \XPP{} describes such events with \emph{global flags},
\begin{lstlisting}
global sign condition {name1=expr1;name2=expr2;...}
\end{lstlisting}
The assignments are made when \texttt{condition} crosses zero from negative to positive (\texttt{sign}$=1$), from positive to negative ($-1$), or in either direction (0). All the right-hand sides are evaluated first, then all the assignments are made together. The names may be state or Markov variables, and \texttt{arret=1} stops the integration.

\paragraph{How events are located.} After every step \XS{} checks each condition. If one has crossed zero in its direction, the crossing time is found on the cubic Hermite interpolant of that step, by regula falsi on the condition. The point just before the event and the point just after the assignments are both stored, at the same time, and integration continues from there. This works with every integrator, including the adaptive and stiff ones, and with maps, where the assignments are applied to the new iterate.

\begin{tryit}
\begin{enumerate}
  \item Load \ui{Bouncing ball}:
\begin{lstlisting}
x'=v
v'=-g
global -1 x {x=0;v=-e*v}
\end{lstlisting}
  Press \key{G}. The status line reports the number of events. The first two bounces occur at $t=\sqrt{2x_0/g}=0.6386$ and $t=0.6386\,(1+2e)=1.7242$, and the computed times agree to six decimal places. Each flight is a parabola in the phase plane (Figure~\ref{fig:ball}). Lower the restitution $e$ with its slider and watch the bounces die away faster.
  \item Load \ui{Integrate-and-fire neuron}:
\begin{lstlisting}
v'=(-v+i-w)/tau
w'=-w/tauw
global 1 v-1 {v=0;w=w+b}
\end{lstlisting}
  Each time $v$ reaches threshold it is reset and the adaptation variable $w$ is kicked up, so the firing rate slows until it settles (Figure~\ref{fig:lif}). With $b=0$ the interspike interval is $\tau\ln\bigl(i/(i-1)\bigr)$, and the computed value agrees to six or more digits.
  \item Add \texttt{global 1 t-50 \{arret=1\}} to a model to stop every run at $t=50$.
\end{enumerate}
\end{tryit}

\begin{figure}[!htbp]
  \centering
  \includegraphics[width=0.55\textwidth]{lif-tc.pdf}
  \caption{Integrate-and-fire neuron with adaptation: $v$ (blue) is reset to 0 at each threshold crossing, while the adaptation current $w$ (red) builds up and lengthens the interspike interval.}
  \label{fig:lif}
\end{figure}

\noindent Equilibria, nullclines and equilibrium continuation ignore flags. Periodic-orbit continuation is switched off for models with flags; use \ui{Sweep max/min} for the long-term behaviour instead.

\section{Tutorial 11: boundary value problems}\label{sec:bvp}

\begin{figure}[!htbp]
  \centering
  \includegraphics[width=0.55\textwidth]{bratu-bif.pdf}
  \caption{Bratu's problem $u''=-\lambda e^u$, $u(0)=u(1)=0$, continued in $\lambda$ with \ui{Continue BVP}. The vertical axis is the slope $u'(0)$. The branch turns round the fold LP1 at $\lambda\approx3.5138$ onto the upper solutions.}
  \label{fig:bratu}
\end{figure}

\XS{} also solves two-point boundary value problems by shooting, using \XPP{}'s syntax. A line \texttt{b} (or \texttt{bndry}) followed by an expression gives a condition that the expression vanishes. In it, a plain name \texttt{u} is the value at the left end and \texttt{u'} the value at the right end. The interval runs from \texttt{t0} (\texttt{@ t0=}, default 0) to \texttt{t0} plus the total time. An unknown parameter, such as an eigenvalue, is written as a variable with zero derivative, \texttt{lam'=0}, so that the numbers of unknowns and conditions match. \texttt{\#@irange u lo hi} gives the initial value of \texttt{u} a slider in the Initial tab.

\begin{tryit}
\begin{enumerate}
  \item Load \ui{Bratu boundary value problem}:
\begin{lstlisting}
u'=up
up'=-lam*exp(u)
b u
b u'
\end{lstlisting}
  Turn on \ui{Solve BVP} above the plot. Newton's method adjusts the initial values until both conditions hold, and the status line reports the largest residual. Moving the $\lambda$ slider solves the problem again at each new value. A boundary value problem has no equilibria to look for, so the phase-plane inspector has no \ui{Find equilibria} button and says where to find its solutions instead.
  \item In the Bifurcation view set the range of $\lambda$ to 0--4, choose \ui{Plot} \texttt{up}, and press \ui{Continue BVP}. Pseudo-arclength continuation in the initial values and $\lambda$ follows the branch round the fold at $\lambda\approx3.5138$ (Figure~\ref{fig:bratu}). Clicking the branch loads that solution.
  \item The examples \ui{Eigenvalue boundary value problem} and \ui{Rotating spiral wave} have a free parameter written as a variable with zero derivative. The spiral-wave example also starts at $t_0=0.01$ to avoid a singular end point.
\end{enumerate}
\end{tryit}

Each figure in a paper usually comes from a sequence of clicks: load a model, set some parameters, continue a branch, start orbits from a Hopf point, change what is plotted, export. \section{Tutorial 13: a forced oscillator and Arnold tongues}\label{sec:torus}

\begin{figure}[!htbp]
  \centering
  \begin{minipage}[t]{0.48\textwidth}\centering
    \includegraphics[width=\textwidth]{torus-locked.pdf}
  \end{minipage}\hfill
  \begin{minipage}[t]{0.48\textwidth}\centering
    \includegraphics[width=\textwidth]{torus-unlocked.pdf}
  \end{minipage}
  \caption{The forced phase oscillator on the torus, $x$ against $y$ (both reduced modulo $2\pi$, so the lines break where they wrap). Left: $\omega=2$, inside the 1:2 tongue; the trajectories from several starts all close in on the same band, the locked orbit. Right: $\omega=2.3$, outside the tongue; the lines do not settle onto a closed orbit.}
  \label{fig:torus}
\end{figure}

In a periodically forced oscillator, or in a phase model, the state lives on a torus. The \ui{Forced phase oscillator} example has two phases, $x$ for the oscillator and $y=\omega t$ for the forcing:
\begin{lstlisting}
p(x)=-sin(x)/(1+a*cos(x))
x'=1+b*p(x)*cos(y)
y'=om
par om=2,b=.25,a=.25
@ fold=x,fold=y,tor_per=6.283185
\end{lstlisting}
Both variables are declared periodic with \texttt{@ fold=}. Plots break where they wrap, and the closing condition of a periodic orbit is taken modulo the period. A locked solution closes in that sense: $x(T)=x(0)+2\pi n$ and $y(T)=y(0)+2\pi m$ with $T=2\pi m/\omega$. Such orbits are followed by the same continuation as limit cycles. The set of parameters for which a locked solution exists is an \emph{Arnold tongue}, and its two edges are folds of cycles.

\begin{tryit}
\begin{enumerate}
  \item Load \ui{Forced phase oscillator} and press \key{G} with $\omega=2$. The trajectory settles onto a locked orbit in which $x$ goes once round while the forcing goes twice (Figure~\ref{fig:torus}, left). Change $\omega$ to $2.3$ and integrate again to see that it is no longer locked.
  \item Return to $\omega=2$, integrate, and open the Bifurcation view. Set the range of \texttt{om} to 1.2--3 and press \ui{Limit cycle}. The locked orbit exists only for $\omega$ between $1.9784$ and $2.0416$: there are two folds of cycles, LPC1 and LPC2, the edges of the 1:2 tongue. The stable and the unstable locked orbit meet at the two folds, so the branch is a closed loop. The continuation stops when it has gone once round, and the status line says that the branch closed up on itself.
  \item Open the Two-parameter view, set the range of \texttt{b} to 0--0.5, and press \ui{Follow} on LPC1 and on LPC2 in the Special points table. The two curves are the edges of the tongue in $(\omega,b)$, and they meet at $b=0$, $\omega=2$.
  \item To add the 1:1 tongue, press \ui{Clear diagram} in the Bifurcation view. This erases the one-parameter branch and leaves the two-parameter curves. Set $\omega=1$, integrate, set the range of \texttt{om} to 0.5--3, continue in \texttt{om} with \ui{Limit cycle} (the folds are at $1.1233$ and $0.8684$), and follow both folds. Turn on \ui{Legend} and \ui{Colours} (Figure~\ref{fig:tongues}).
\end{enumerate}
\end{tryit}

\begin{figure}[!htbp]
  \centering
  \includegraphics[width=0.78\textwidth]{tongues.pdf}
  \caption{The 1:1 and 1:2 Arnold tongues of the forced phase oscillator in $(\omega,b)$, as curves of folds of cycles. Each tongue has two edges, and the legend says which fold and which value of $\omega$ each curve was started from. The dashed lines mark the current parameter values.}
  \label{fig:tongues}
\end{figure}

\noindent The tongue is the region between the two edges, widening as the forcing $b$ grows. Narrower tongues, such as 1:3, are harder to reach: at $\omega=3$ the default run does not settle onto a locked orbit, so you need a longer integration or a starting point on the orbit. One-parameter diagrams add up in the same way: continuing the orbit in $\omega$ at three values of $b$ keeps three branches on the same axes, and \ui{Legend} tells them apart by the value of $b$.

\section{Tutorial 14: homoclinic and heteroclinic orbits}\label{sec:conn}

\begin{figure}[!htbp]
  \centering
  \begin{minipage}[t]{0.48\textwidth}\centering
    \includegraphics[width=\textwidth]{nagumo-front.pdf}
  \end{minipage}\hfill
  \begin{minipage}[t]{0.48\textwidth}\centering
    \includegraphics[width=\textwidth]{nagumo-curve.pdf}
  \end{minipage}
  \caption{The Nagumo front. Left: the heteroclinic orbit in the $(u,v)$ plane, from the saddle at $u=1$ to the saddle at $u=0$ (squares), with the focus at $u=a$ (dot). Right: the speed $c$ at which it exists, followed in $a$ from 0.05 to 0.45. The points lie on the exact line $c=(1-2a)/\sqrt2$ to about $10^{-9}$.}
  \label{fig:nagumo}
\end{figure}

A \emph{homoclinic orbit} leaves a saddle and comes back to it; a \emph{heteroclinic orbit} joins two saddles. Both exist only for special values of a parameter: they are codimension one, so a one-parameter diagram shows them as single points where a family of orbits ends. They matter for waves. Written in a frame moving with speed $c$, a travelling front of a reaction--diffusion equation is a heteroclinic orbit of an ordinary differential equation between two rest states, and a pulse is a homoclinic orbit. The speed $c$ is the parameter that has to be tuned until the connection exists.

\paragraph{How the orbit is found.} The orbit starts a small distance from the first saddle, along the eigenvector of its single unstable eigenvalue, and is integrated until it comes closest to the second. There the program measures on which side of the second saddle's stable manifold it passes, using the unstable eigenvector of the second saddle. The measure changes sign at a connection. \XS{} scans the range of the continuation parameter for a sign change, narrows it down by false position (the Illinois variant, which needs far fewer integrations than bisection), and accepts the result only if the orbit really goes on to the target. \ui{Follow} then steps a second parameter and solves again for the first near the previous value, in both directions.

\paragraph{The controls} are in the section \ui{Homoclinic and heteroclinic orbits} of the Bifurcation panel, under the continuation buttons. The menus \ui{From} and \ui{To} list the equilibria found in the phase plane at the current parameters, and any saddle found at the end of a branch of periodic orbits (below). \ui{Find connecting orbit} searches the range of the continuation parameter, reporting its progress in the status line. While it searches, the button becomes \ui{Stop}: press it, or \key{Esc}, to end a search that is taking too long. \ui{Follow} can be ended the same way: \key{Esc} moves on to the other direction, and \ui{Stop} in the Two-parameter view (or \key{Shift}+\key{Esc}) ends it, keeping the points found so far. The orbit found is drawn in the phase plane and becomes a point of the diagram, HOM1, HET1, \ldots{} in the table of special points. On the diagram it is marked by diamonds at the maximum and minimum of the plotted variable along the orbit, at its $L^2$ norm in the L2 view (for a homoclinic orbit, the norm of the saddle, the limit of the norms of periodic orbits that approach it), at zero frequency, and by a dashed line in the period view, where the period is infinite. Clicking its row moves to it and draws it again. \ui{Follow} in its row continues it in Parameter~2 of the Two-parameter view, over the range set there; the curve is drawn in the Two-parameter view in its own colour, and HOM1 and HET1 also appear under \ui{Start} there.

\textbf{The Nagumo front.}

  \item In the Two-parameter view, Parameter~2 is $a$. Press \ui{Follow} on HET1 in the special points table (or choose HET1 under \ui{Start} and press \ui{Follow curve}). In a second or two the curve of speeds over $0.05\le a\le0.45$ appears (Figure~\ref{fig:nagumo}, right), and a note placed on it (Section~\ref{sec:notes}) can carry the formula.
\end{enumerate}
\end{tryit}

\paragraph{Homoclinic orbit or SNIC?} \emph{hi-slo-lo} under \ui{Show} (Tutorial~2) draws where the orbits of a family move slowly: on the Morris--Lecar example above, a line of slow points appears near the end of the HB1 branch and runs into the saddle at $v=-22.3$, and in the class~1 case below it runs into the fold. \paragraph{When to run time backwards.} The method needs the starting saddle to have exactly one real unstable direction, and the target saddle too, with all the other directions stable. If instead the starting saddle has a one-dimensional \emph{stable} manifold and a bigger unstable one, as can happen at the rest state of a pulse, tick \ui{Run time backwards}. The orbit is then followed from \ui{To} back to \ui{From}, which turns the one-dimensional stable manifold into the starting direction.

\paragraph{Limits.}
\begin{itemize}
  \item Both equilibria must be saddles with one real unstable direction (counted backwards in time if \ui{Run time backwards} is ticked). Saddles with complex unstable eigenvalues, or with a two-dimensional unstable manifold at both ends, are not handled.
  \item \ui{Follow} steps Parameter~2 and solves for Parameter~1, so a curve that turns back in Parameter~2 is lost at the turn. The status line says whether the curve ended at the edge of a range or because the connection was lost.
  \item The method has been tested on planar problems, where the answers above are exact or checked. For systems with three or more variables, check an orbit by integrating it, and do not rely on a failure to find one as proof that none exists: the range of Parameter~1 and the choice of equilibria matter.
  \item The orbit is not tested for stability, and codimension-two points are not located on the curve. Orbits found are not saved in the \texttt{.ode} file, but a script can find them again with \texttt{connect} and follow them with \texttt{follow} (Section~\ref{sec:script}).
  \item The saddle at the end of a branch is only looked for when the period is still rising over the last few orbits and has at least doubled along the branch. If the branch stopped for another reason first (the point limit, say), raise the limit and continue again, or choose the saddle by hand.
\end{itemize}

\section{Tutorial 15: phase reduction of a periodic orbit}\label{sec:adjoint}

\begin{figure}[!htbp]
  \centering
  \includegraphics[width=\textwidth]{ui-phase.png}
  \caption{The Phase reduction view, here with the coupled Ginzburg--Landau oscillators of Section~\ref{sec:cgl}. The chips above the plot choose what is drawn: the orbit itself, the adjoint $Z$, the isostable response $I$, the Floquet eigenfunction $\rho$, the correction $B$, the interaction function $H$ and its second-order version $H_2$, with the coupling strength $\epsilon$ beside the last. On the right are the \ui{Adjoint} button, the choice of where the orbits come from, and a note on the slowest Floquet multiplier $\nu_1$.}
  \label{fig:phaseview}
\end{figure}

A limit cycle can be described by a single \emph{phase} $\theta$ that advances at a constant rate. Weakly coupled oscillators are then studied through how a small push changes the phase: the \emph{adjoint} $Z(t)$, or phase response curve, and from it the \emph{interaction function} $H$ that decides whether two coupled oscillators synchronise \cite{ermentrout2010,kuramoto1984}. This is the first-order theory. It misses everything that depends on how strongly the oscillators are coupled, because the shape of $H$ cannot change with the coupling strength. The second-order theory of Wilson and Ermentrout \cite{wilson2019} adds the decaying \emph{amplitude} of the orbit as a second coordinate (an \emph{isostable} coordinate \cite{wilson2018}), and finds how locked states appear, disappear and change stability as the coupling grows.

\XS{} computes all of this in one place, the \ui{Phase reduction} view (the sixth button above the plot, or the key \key{6}). Everything starts from the \ui{Adjoint} button in its panel, which takes a periodic orbit, or several, and computes the adjoint $Z$; the slowest Floquet multiplier $\nu_1$ and, when it allows, the isostable response $I$, the Floquet eigenfunction $\rho$ and a correction $B$ to the phase response; and, if the model has coupling lines, $H$ and the second-order functions $g_2$, $g_3$ and the coefficient $\gamma$. The chips above the plot choose which of these is drawn.

\ui{Adjoint} turns blue when there is something new for it: a continued family of periodic orbits for the current parameter, or a trajectory that has settled onto a limit cycle. Its menu chooses between the two, \emph{Current periodic branch} and \emph{Current periodic orbit}, and an entry with nothing to work on is greyed out; until you choose by hand it follows what there is, the branch if there is one and otherwise the orbit. Once \ui{Adjoint} has been pressed it goes back to normal until there is a new family or a new cycle.

\subsection*{The adjoint $Z$}

\begin{figure}[!htbp]
  \centering
  \includegraphics[width=0.78\textwidth]{ml-adjoint.pdf}
  \caption{The adjoint $Z_v(t)$ of the Morris--Lecar limit cycle at eight values of the applied current $i$, from 150 (dark) to 198 (light), against the phase $t/T$ with phase 0 at the maximum of $v$. As $i$ increases the negative lobe deepens and moves later in the cycle. Made by the script on page~\pageref{lst:adjscript}.}
  \label{fig:adjoint}
\end{figure}

Let $X'=F(X)$ have a periodic orbit $U(t)$ of period $T$ and write $A(t)=D_XF(U(t))$. The adjoint is the $T$-periodic solution of
\begin{equation}
  Z'=-A(t)^{\mathsf T}Z,\qquad Z(t)^{\mathsf T}U'(t)=1.
\end{equation}
A small kick $\delta$ given to the oscillator at time $t$ advances it, once it has settled back onto the orbit, by $Z(t)^{\mathsf T}\delta$ units of time. The normalisation $Z^{\mathsf T}U'=1$ holds for all $t$ once it holds at $t=0$, and \XS{} reports how well it holds as a check.

\paragraph{How it is computed.} For each orbit the variational equation is integrated once around the cycle, which gives the monodromy matrix $\Phi(T,0)$. Since $Z(t)^{\mathsf T}\Phi(t,0)$ does not change with $t$, $Z(0)$ is the left eigenvector of $\Phi(T,0)$ for the multiplier~1, scaled so that $Z(0)^{\mathsf T}U'(0)=1$. $Z$ is then carried back around the orbit with the transposes of the same steps, which makes it exactly periodic. The orbit comes from the shooting points of the continuation, and is polished with a few Newton steps so that it closes on the fine grid (800 points per period, more if the check below asks for it). Because the eigenvector is found directly, nothing has to converge over many periods, so the method works for unstable orbits as well as stable ones, and in the middle of a family as well as at its ends.

\paragraph{Accuracy.} The status line gives the largest error found, the largest deviation of $Z^{\mathsf T}U'$ from~1 over the orbit and of $Z$ from periodicity. For the Stuart--Landau oscillator, where $Z=(-\sin\omega t,\allowbreak\cos\omega t)/(\omega\sqrt\mu)$ is known exactly, the error is below $10^{-8}$; for Morris--Lecar it is about $10^{-7}$ or less. It is larger for orbits very close to a fold of cycles, where a second multiplier is almost~1 and $Z$ is sensitive to any error, and the status line then says so. As a check against the definition, kicks of 0.5\,mV and smaller applied to the Morris--Lecar orbit shift the phase by $Z^{\mathsf T}\delta$ to within a relative error that goes to zero as the kick is made smaller.

\subsection*{Beyond the phase: $\nu_1$, $I$, $\rho$ and $B$}\label{sec:isostable}

The monodromy matrix has the multiplier~1, which belongs to the phase, and the other multipliers $\nu_j$, which say how fast a displacement from the orbit dies away (or grows, if it is unstable). Let $\nu_1$ be the \emph{slowest nontrivial} one, meaning the one with the smallest $|\ln|\nu||$; for a stable orbit this is the multiplier of largest modulus below~1. Write $\kappa=\ln\nu_1/T$. Near the orbit a state can be written
\begin{equation}
  X=U(\theta)+\psi\,\rho(\theta),\qquad \theta'=1,\quad \psi'=\kappa\psi,
\end{equation}
where $\psi$ is the \emph{isostable} amplitude: the distance from the orbit along the slow direction, which decays like $e^{\kappa t}$. Three more periodic functions go with it:
\begin{align}
  \rho'&=\bigl(A(t)-\kappa\bigr)\rho, \\
  I'&=\kappa I-A(t)^{\mathsf T}I,\qquad I^{\mathsf T}\rho=1, \\
  B'&=-\bigl(A(t)^{\mathsf T}+\kappa\bigr)B-\bigl(D^2F(U)[\rho]\bigr)^{\mathsf T}Z .
\end{align}
$\rho$ is the Floquet eigenfunction for $\nu_1$. $I$ is the \emph{isostable response}: a kick $\delta$ at time $t$ changes $\psi$ by $I(t)^{\mathsf T}\delta$, just as it changes the phase by $Z(t)^{\mathsf T}\delta$. $B$ is the first correction to the phase response off the orbit: the gradient of the phase at the point $U(\theta)+\psi\rho(\theta)$ is $Z(\theta)+\psi B(\theta)+O(\psi^2)$. In its equation $D^2F(U)[\rho]$ is the derivative of $A(t)=DF(U(t))$ in the direction $\rho$. Besides these, $I^{\mathsf T}U'=0$ and $Z^{\mathsf T}\rho=0$ hold all along the orbit. Wilson and Ermentrout \cite{wilson2019} call the corresponding functions $Z$, $I$, $B$ and $C$; the last, the correction to $I$, is not needed for the second-order coupling functions and is not computed.

\paragraph{How they are computed.} $\rho(0)$ and $I(0)$ are the right and left eigenvectors of the same monodromy matrix for $\nu_1$. $I$ is carried back around the orbit with the transposes of the integration steps, as $Z$ is, and $\rho$ forward with the steps themselves; at every step the components along $U'$ (in $\rho$) and along $Z$ (in $I$), which are exactly zero, are removed. $B$ is the periodic solution of an affine recursion over the same steps, which exists and is unique unless some multiplier equals $1/\nu_1$. $D^2F[\rho]$ is taken by central differences of the Jacobian along $\rho$. As with $Z$, \XS{} reports the errors found: $I^{\mathsf T}\rho$ against~1, $Z^{\mathsf T}\rho$ and $I^{\mathsf T}U'$ against~0, and the closure of $\rho$, $I$ and $B$ after one period. For the coupled Ginzburg--Landau oscillators of Section~\ref{sec:cgl}, where all four functions are known in closed form, the computed ones agree to about $10^{-9}$ ($10^{-8}$ for $B$).

\paragraph{Conventions.} $\rho$ is scaled so that its Euclidean norm has maximum~1 over the orbit, and signed so that it points outward from the centre of the orbit on average; $I$ is then fixed by $I^{\mathsf T}\rho=1$. The amplitude $\psi$ is measured in these units, so rescaling $\rho$ by a factor $c$ divides $\psi$ and $I$ by $c$ and multiplies $B$ by $c$; the products $\psi\rho$, $I^{\mathsf T}\delta$ and $\psi B$ do not change. A function quoted in a paper with another scaling therefore differs from the one drawn here by such a factor (Section~\ref{sec:cgl} gives an example). \ui{Export CSV} says which convention was used.

\begin{notebox}
\textbf{When are $I$, $\rho$ and $B$ not drawn?} They belong to one \emph{real, positive} slowest multiplier. When that is not so, \XS{} skips them, says why in the note on the right and in the key, and still computes $Z$, the orbit and $H$.
\begin{itemize}
  \item \textbf{A complex pair.} If the slowest multipliers are a complex-conjugate pair, two isostable coordinates are needed, which \XS{} does not compute (see \cite{wilson2019pre} for the theory).
  \item \textbf{A negative multiplier.} Then $\rho$ and $I$ change sign over one period and have period $2T$; this happens next to a period doubling. They are not computed.
  \item \textbf{A multiplier near~1.} Within about $10^{-6}$ of~1 the orbit is at a bifurcation, and the functions are meaningless. The same holds if two real multipliers are equal.
  \item \textbf{A multiplier of zero.} If $|\nu_1|<10^{-10}$ the amplitude dies away so fast that there is nothing to resolve. This is common for strongly attracting relaxation oscillations (we found about $10^{-17}$ for a FitzHugh--Nagumo oscillator with a small time-scale ratio), and the examples here, with $\nu_1$ between $3\times10^{-6}$ and $0.07$, are all well inside the range that works.
  \item \textbf{An unstable orbit} ($\nu_1>1$). The functions are computed, but an isostable expansion about an unstable orbit is only formal; $H_2$ says so.
\end{itemize}
Along a family the choice is made orbit by orbit: the functions are drawn for the orbits that have them, and the key says how many do not and why.
\end{notebox}

\subsection*{Coupled oscillators: the interaction function $H$}\label{sec:hfun}

Two identical oscillators with weak coupling, $X_1'=F(X_1)+\epsilon G(X_1,X_2)$ and $X_2'=F(X_2)+\epsilon G(X_2,X_1)$, reduce to phase equations $\theta_1'=1+\epsilon H(\theta_2-\theta_1)$, $\theta_2'=1+\epsilon H(\theta_1-\theta_2)$ with the interaction function
\begin{equation}
  H(\phi)=\frac1T\int_0^T Z(t)^{\mathsf T}\,G\bigl(U(t),U(t+\phi)\bigr)\,dt .
\end{equation}
The phase difference $\phi=\theta_2-\theta_1$ then obeys $\phi'=\epsilon\,[H(-\phi)-H(\phi)]=-2\epsilon H_{\mathrm{odd}}(\phi)$, where $H_{\mathrm{odd}}(\phi)=\tfrac12[H(\phi)-H(-\phi)]$ is the odd part. A zero of $H_{\mathrm{odd}}$ is a phase-locked state; it is stable (for $\epsilon>0$) where $H_{\mathrm{odd}}$ crosses zero upwards. The synchronous state $\phi=0$ and the anti-phase state $\phi=T/2$ are always zeros, by symmetry.

\paragraph{The form of the coupling.} The coupling is written in the equations, one line for each variable that receives input:
\begin{lstlisting}
#@coupling v: v'-v
#@coupling ca: dcs*(ca'-ca)
\end{lstlisting}
\noindent The expression is that component of $G(X,X')$, where $X$ is the cell itself and a primed name (\texttt{v'}) is the same variable of the partner; a variable with no line gets no coupling. \XPP{} reads these lines as comments. Three points matter.
\begin{itemize}
  \item \textbf{$\epsilon$ is not in the line.} The lines give $G$ and nothing else. The overall strength $\epsilon$ in $\epsilon G(X,X')$ is not part of the model: in $H$ it is understood to multiply the result, and in the second-order functions below it is the number in the field next to the $H_2$ chip. A factor inside the expression, such as \texttt{dcs} above, or a synaptic conductance, is a part of $G$ and not of $\epsilon$. Parameters like these may appear in the line, and $H$ follows them as they are changed.
  \item \textbf{Pairs only.} The theory used is that of two identical cells with symmetric coupling. Networks, and unequal or one-way weights, are not treated.
  \item \textbf{$G$ must be smooth.} The second-order functions need the derivatives of $G$ with respect to both of its arguments, which are taken numerically. A coupling that is not differentiable (an absolute value, say) will give poor second-order results, though $H$ itself is unaffected.
\end{itemize}

\noindent To check a result by direct simulation, write two copies of the model with the coupling terms added explicitly, $X_1'=F(X_1)+\epsilon G(X_1,X_2)$ and $X_2'=F(X_2)+\epsilon G(X_2,X_1)$.

When the model has coupling lines, an \ui{H} chip appears next to the others. It shows $H$ against the phase shift $\phi/T$; a menu beside it chooses $H$, its even part $\tfrac12[H(\phi)+H(-\phi)]$, its odd part, or all three (solid, dashed and dotted). For a single orbit the zeros of the odd part are marked, filled where stable and open where unstable, and listed under the curves. The curves are coloured by the parameter, as for $Z$. \ui{Export CSV} writes all three parts for every orbit, together with a second file of Fourier coefficients (Section~\ref{sec:fourier}), and \texttt{hfunction} in a script does the same job as the chip.

\noindent Because $H$ only needs the stored $U$ and $Z$, it is recomputed whenever a parameter changes, which takes a few milliseconds for a family of orbits. You can therefore drag the slider for a coupling strength or a synaptic reversal potential and watch $H$ change, with the axes only growing while you drag (press \ui{Fit} to rescale). For each orbit $H$ is computed with the continuation parameter at the value of that orbit and every other parameter at its present value. \XS{} does not check whether a change has altered the cycle itself: if it has (the applied current, say), press \ui{Adjoint} again. Moving the slider of the continuation parameter leaves $H$ as it is.

\subsection*{Second order: $H_2$ and $\gamma$}\label{sec:hsecond}

To first order the locking equation $\phi'=\epsilon\,g_1(\phi)$, with $g_1(\phi)=H(-\phi)-H(\phi)$, has a right-hand side whose \emph{shape} does not depend on $\epsilon$. So it can never show a locked state losing stability, or a new one appearing, as the coupling is made stronger, although both happen in real oscillators. The next order does \cite{wilson2019}. With the amplitude of each cell $\psi_i=\epsilon r_i$ eliminated, the phase difference obeys
\begin{equation}
  \phi'=\epsilon\,\bigl[g_1(\phi)+\epsilon\,\bigl(g_2(\phi)+g_3(\phi)\bigr)\bigr],
\end{equation}
with $g_2(\phi)=A(-\phi)-A(\phi)$ and $g_3(\phi)=B_f(-\phi)-B_f(\phi)$, where
\begin{equation}
  A(\phi)=\bigl\langle f_\phi(t)\,h_2(t,t+\phi)\bigr\rangle,\qquad
  B_f(\phi)=\bigl\langle f_{-\phi}(t+\phi)\,h_3(t,t+\phi)\bigr\rangle,
\end{equation}
\begin{align}
  h_2(t,s)&=Z(t)^{\mathsf T}\bigl[G_1(U(t),U(s))\,\rho(t)\bigr]+B(t)^{\mathsf T}G(U(t),U(s)),\\
  h_3(t,s)&=Z(t)^{\mathsf T}\bigl[G_2(U(t),U(s))\,\rho(s)\bigr],
\end{align}
$G_1$ and $G_2$ are the derivatives of $G$ with respect to its first and second arguments, $\langle\cdot\rangle$ is the average over one period, and $f_\phi$ is the periodic solution of $f'=\kappa f+I(t)^{\mathsf T}G(U(t),U(t+\phi))$. \XS{} finds $f_\phi$ exactly, term by term in a Fourier series, so there is no integral to truncate. The functions $g_2$ and $g_3$ are odd and periodic, so synchrony and anti-phase remain locked states at every $\epsilon$, but their stability can change, and new states can appear in pairs.

\paragraph{The $H_2$ chip.} The functions $A$ and $B_f$ are the second-order counterparts of $H$. With $H_2(\phi)=A(\phi)+B_f(\phi)$, each cell obeys $\theta_i'=1+\epsilon\,[H+\epsilon H_2](\theta_j-\theta_i)$, and the phase difference obeys
\begin{equation}
  \phi'=-2\epsilon\,\mathrm{odd}\bigl[H+\epsilon H_2\bigr](\phi),
\end{equation}
so that $g_1=-2H_{\mathrm{odd}}$ and $g_2+g_3=-2\,\mathrm{odd}[H_2]$. The \ui{H$_2$} chip, which appears next to \ui{H} when $I$, $\rho$ and $B$ are available, therefore works like the $H$ chip, with a field for $\epsilon$ and the same menu for the part that is drawn: the whole function, its even part, its odd part, or all three. Both cells use the same $G$ as the $H$ chip.
\begin{itemize}
  \item With $\epsilon=0$ it shows $H_2$ itself (or its even or odd part): the shape of the second-order correction.
  \item With $\epsilon\neq0$ it shows $H+\epsilon H_2$. When one part is drawn, the same part of the first-order $H$ is drawn dashed in grey for comparison. The zeros of the odd part are the locked states, marked filled where stable and open where unstable, and listed under the curves. As for $H$, a zero is stable where the odd part crosses zero upwards if $\epsilon>0$ (downwards if $\epsilon<0$; negative $\epsilon$ is allowed). The even part does not enter the equation for the phase difference, but it gives the common rate of advance of a locked pair.
  \item The menu has one more entry, $\phi'/\epsilon$, which draws $g_1+\epsilon(g_2+g_3)=-2\,\mathrm{odd}[H+\epsilon H_2]$, the rate of change of the phase difference as plotted in Figure~2 of \cite{wilson2019}, with $g_1$ dashed (at $\epsilon=0$ it draws $g_2+g_3$). A stable state is then a zero where the curve crosses downwards.
  \item Changing $\epsilon$ recombines functions that are already computed, so it is instant.
\end{itemize}
The \ui{Export CSV} file has $g_1$, $g_2$, $g_3$, $g_2+g_3$, the composite for the present $\epsilon$, the two parts $H_{24}(\phi,\phi)$ and $H_{34}(\phi,0)$ of $H_2$, and $H_2$ and $H+\epsilon H_2$; these are the functions themselves, without $\epsilon$, except for the two composite columns, which use the value in the field. A second file holds their Fourier coefficients. In a script, \texttt{hsecond eps=0.1 show=odd} and \texttt{phasefn H2} do the same; \texttt{show} takes \texttt{all}, \texttt{H}, \texttt{even}, \texttt{odd} or \texttt{rate}.

\paragraph{The coefficient $\gamma$.} The legend gives
\begin{equation}
  \gamma=\tfrac14\bigl[g_2'(0)+g_3'(0)\bigr]
\end{equation}
for each orbit, and for a single orbit also the two numbers $-A'(0)$ and $-B_f'(0)$ from which it is made. For diffusive coupling $G(X,X')=D(X'-X)$ these are equal, and $\gamma$ is the coefficient of the fourth-derivative term in the Kuramoto--Sivashinsky equation $\phi_t=\epsilon(\beta\phi_x^2+\alpha\phi_{xx}+\gamma\phi_{xxxx})$ that describes a continuum of such oscillators \cite{wilson2019,kuramoto1984}. It is the term that matters when the diffusion coefficient $\alpha=H'(0)$ is small. The program reports both numbers, so that for other couplings you can see how far they differ: the equality is a property of diffusive coupling, and is a useful check on a model's coupling lines.

\paragraph{Fourier coefficients, for networks.}\label{sec:fourier} To put these functions into a model of many oscillators it is easier to have them as formulas than as tables. \ui{Export CSV} in the $H$ or $H_2$ mode therefore writes a second file, with the same name and \texttt{-fourier} added, that holds the first 20 Fourier coefficients of the functions, for each orbit:
\begin{equation}
  F(\phi)=a_0+\sum_{k=1}^{20}\Bigl[a_k\cos\frac{2\pi k\phi}{T}+b_k\sin\frac{2\pi k\phi}{T}\Bigr],
\end{equation}
with $\phi$ the time shift and $T$ the period (the periods are in the comment lines; in the file the rows are $k=0,\dots,20$ and the columns are \texttt{F\_a} and \texttt{F\_b} for each function $F$). In the $H$ mode the file has $H$; in the $H_2$ mode it has $H$, $H_{24}(\phi,\phi)$, $H_{34}(\phi,0)$, $H_2$ and $g_2+g_3$. Since $g_2+g_3=-2\,\mathrm{odd}[H_2]$ is odd, its cosine coefficients are zero and $b_k(g_2+g_3)=-2\,b_k(H_2)$. Like the functions, the coefficients do not contain $\epsilon$.

Twenty harmonics are plenty for a smooth cycle. For the Hodgkin--Huxley example the amplitude $\sqrt{a_k^2+b_k^2}$ of $H$ falls from about 2 at $k=1$ to $4\times10^{-5}$ at $k=10$ and $3\times10^{-6}$ at $k=20$; for the Ginzburg--Landau oscillators only $k\le2$ are present, and the computed coefficients agree with the exact ones to $10^{-9}$. The coefficients are found from 100 samples of each function over a period, so they should not be used much beyond $k=20$. A short script for a network of $N$ cells then needs only the coefficients: at first order, $\theta_i'=1+\epsilon\sum_j a_{ij}H(\theta_j-\theta_i)$ with $H$ the series above.

\emph{The second order is not complete for a network.} The functions $H_{24}(\phi,\phi)$ and $H_{34}(\phi,0)$ are the terms of the network equation of \cite{wilson2019} that involve one neighbour: for weights $a_{ij}$ they enter as $\epsilon^2\sum_j\bigl[a_{ij}^2H_{24}(\phi_{ij},\phi_{ij})+a_{ij}a_{ji}H_{34}(\phi_{ij},0)\bigr]$, with $\phi_{ij}=\theta_j-\theta_i$, which is why they are written out separately. For symmetric weights equal to~1 the sum is $H_2$. The terms that involve two different neighbours of the same cell need the full two-argument functions $H_{24}(\eta,\xi)$ and $H_{34}(\eta,\xi)$, which \XS{} does not compute. They can be computed from the file written with the \ui{Orbit} chip, together with the coupling function $G$ and its derivatives, which you supply: $H_{24}(\eta,\xi)=\langle f_\xi(t)\,h_2(t,t+\eta)\rangle$ and $H_{34}(\eta,\xi)=\langle f_{\xi-\eta}(t+\eta)\,h_3(t,t+\eta)\rangle$, with $h_2$, $h_3$ and $f_\phi$ as defined above. The two functions in the exported table are the cases $\xi=\eta$ and $\xi=0$, and serve to check such a calculation. So $H+\epsilon H_2$ is exact for a pair, and a useful but incomplete second-order correction for a network.

\paragraph{How far to trust it.} The expansion is accurate to $O(\epsilon^2)$ in the coupling strength, and it assumes that the other multipliers are small compared with $\nu_1$, so that one isostable coordinate is enough. For a model with two variables this is automatic. Otherwise the legend gives the ratio of the next multiplier to $\nu_1$ whenever it exceeds $\tfrac14$, and also warns when $|\kappa|T<0.3$, when the slowest multiplier is close to~1 and the expansion breaks down as the orbit nears a bifurcation, and when the orbit is unstable. The computation costs about five times as much as $H$ (it evaluates $G$ and its derivatives at every point of the orbit for each of 100 phase shifts), so \XS{} computes it only while the $H_2$ chip is on, and again when a parameter is changed while it is on.

\subsection*{An example with exact answers: coupled Ginzburg--Landau oscillators}\label{sec:cgl}

The complex Ginzburg--Landau oscillator, in real coordinates and with a pair of cells $j=1,2$, $k=3-j$, is \cite{wilson2019}
\begin{align}
  x_j'&=x_j(1-x_j^2-y_j^2)-q(x_j^2+y_j^2)\,y_j+\epsilon\bigl[x_k-x_j-d\,(y_k-y_j)\bigr],\\
  y_j'&=y_j(1-x_j^2-y_j^2)+q(x_j^2+y_j^2)\,x_j+\epsilon\bigl[y_k-y_j+d\,(x_k-x_j)\bigr].
\end{align}
It is the model \ui{Coupled Ginzburg--Landau oscillators} in the Model menu. Its equations are
\begin{lstlisting}
x'=x*(1-x^2-y^2)-q*(x^2+y^2)*y
y'=y*(1-x^2-y^2)+q*(x^2+y^2)*x
par q=1,d=0.9
init x=1,y=0
#@coupling x: (x'-x)-d*(y'-y)
#@coupling y: (y'-y)+d*(x'-x)
@ total=40,dt=0.01,meth=rk4,xp=x,yp=y
done
\end{lstlisting}
The first two lines are one cell. The two coupling lines are $G(X,X')$, the part of the equations multiplied by $\epsilon$, and the strength $\epsilon$ itself is not in the file (as explained above). The other parameters, $q$ and $d$, are part of $G$ or of the cell, and can be moved with their sliders.

\paragraph{The exact answers.} Uncoupled, a cell has the limit cycle $U=(\cos qt,\sin qt)$ of period $T=2\pi/q$ and a single nontrivial multiplier, so that $\kappa=-2$ and $\nu_1=e^{-4\pi/q}$. Write $C=\cos qt$ and $S=\sin qt$. In the scaling of \cite{wilson2019},
\begin{equation}
  Z=\bigl(C-S/q,\ S+C/q\bigr),\quad
  \rho=\bigl(qS+C,\ S-qC\bigr),\quad
  I=\bigl(C,\ S\bigr),\quad
  B=\frac{1+q^2}{q}\bigl(S,\ -C\bigr).
\end{equation}
\XS{} scales $\rho$ so that its norm has maximum~1, which divides $\rho$ by $\sqrt{1+q^2}$; $I$ is then multiplied by $\sqrt{1+q^2}$ and $B$ divided by it (the rule in the conventions above), while $Z$ is unchanged. With phase~0 at the maximum of $x$, which is where the trajectory starts, these are exactly the curves drawn, with $C$ and $S$ evaluated at $t/T$ in place of $qt/2\pi$. The locking equation is
\begin{equation}
  \phi'=-\epsilon\,\frac2q\,\sin q\phi\,\bigl[\,1-dq+\epsilon d^2(1+q^2)\cos q\phi\,\bigr].
\end{equation}
So $g_1(\phi)=-\frac2q(1-dq)\sin q\phi$ and $g_2(\phi)+g_3(\phi)=-\frac{d^2(1+q^2)}{q}\sin 2q\phi$, and $\gamma=-\tfrac12d^2(1+q^2)$. To first order synchrony is stable if and only if $1-dq>0$, and anti-phase if and only if $1-dq<0$ (for $\epsilon>0$). The exact critical couplings, at which synchrony and anti-phase change stability \cite{aronson1990}, are
\begin{equation}
  \epsilon_s=\frac{dq-1}{d^2+1},\qquad \epsilon_a=\frac{1-dq}{d^2-2dq+3},
\end{equation}
and the second-order theory replaces them by
\begin{equation}
  \epsilon_{s,\mathrm{approx}}=\frac{dq-1}{d^2(1+q^2)},\qquad \epsilon_{a,\mathrm{approx}}=\frac{1-dq}{d^2(1+q^2)}.
\end{equation}
The two agree near $d=1/q$, where both are zero, and the approximate curves are tangent to the exact ones there.

\subsection*{A single orbit, in one press of \ui{Run}}\label{sec:adjhere}

To study one set of parameter values you do not need a family. In the Phase reduction view set the menu to \emph{Current periodic orbit} (the number of orbits and the range then disappear), integrate a trajectory until it has settled onto its limit cycle, and press \ui{Adjoint}; in a script, \texttt{adjoint here}. \XS{} finds the periodic orbit at the end of the active trajectory, as the first step of \ui{Limit cycle} does, but at the present parameters and without continuing it, and computes everything above for it.

The choice then stays on, and \XS{} follows the trajectory \emph{while the Phase reduction view is open}. After a \ui{Run} (or an automatic run) that has changed the cycle, it finds the orbit again and recomputes $Z$, $I$, $\rho$, $B$, $H$ and $H_2$, so that setting parameters and pressing \ui{Run} gives everything at once, and the chip that you have chosen stays chosen. In the other views nothing is recomputed: the results are only marked as out of date, and are brought up to date once when you return to the Phase reduction view, so you can go on working in the phase plane without paying for them. To stop following altogether, untick \ui{Follow the trajectory} in the panel (in a script, \texttt{adjoint follow=off}, or \texttt{adjoint off}, which also hides the curves); the results then stay as they are until you press \ui{Adjoint} again. It decides whether the cycle has changed by sampling the right-hand side along the stored orbit: a change of a coupling parameter alone leaves the orbit as it is and only updates $H$ and $H_2$. When a slider is dragged the update waits until you pause, and with Auto-update unticked it is done by \ui{Run}. Pressing \ui{Adjoint} along a family replaces it. The trajectory must have settled onto a \emph{stable} limit cycle by the end of its total time, as for \ui{Limit cycle}, and if it has not the status line says so and the previous result is kept. An unstable orbit needs continuation from a Hopf point.

\noindent The Hodgkin--Huxley model of the squid axon, with coupling through the voltage, is in the Model menu; its equations are

\subsection*{Checks}

\paragraph{First order.} For the Stuart--Landau oscillator with \texttt{\#@coupling x: x'-x} and \texttt{\#@coupling y: y'-y}, $H(\phi)=\sin(2\pi\phi/T)/\omega$ exactly; the computed $H$ agrees to about $10^{-9}$, has no even part, and shows synchrony stable. For two Morris--Lecar cells simulated directly with $\epsilon=0.002$, started at five different phase differences, the measured rate of change of the phase difference agrees with $\epsilon\,[H(-\phi)-H(\phi)]$ to within about $5\%$, the difference being the next order in $\epsilon$. The same test on the Hodgkin--Huxley result above gives the right direction of drift at all five starting phases (towards $0$ or $\tfrac12$, away from $0.38$ and $0.62$), with the size within $1\%$ at three of them and within $13\%$ at the other two, where the drift is smallest.

\paragraph{Isostable functions.} For the Ginzburg--Landau oscillator the computed $Z$, $\rho$, $I$ and $B$ agree with the closed forms to about $10^{-9}$ (for $B$, $10^{-8}$) at $q=1$ and at $q=1.7$, and $\kappa=-2$ to $3\times10^{-9}$. For a model without a closed form, van der Pol with $\mu=0.7$, the phase response was measured directly: points displaced from the orbit by $\pm0.02\rho$ were integrated until they had settled onto the cycle, and the gradient of the resulting phase compared with $Z+\psi B$. The derivative of the measured gradient with respect to $\psi$ agrees with $B$ to $10^{-5}$ at three places on the orbit, the size of the $O(\psi^2)$ error of the measurement itself.

\paragraph{Second order.} For the Ginzburg--Landau model with $q=1.7$ and $d=0.9$, $g_1$ agrees with the exact $-\frac2q(1-dq)\sin q\phi$ to $1.5\times10^{-9}$ and $g_2+g_3$ with $-\frac{d^2(1+q^2)}{q}\sin2q\phi$ to $3\times10^{-8}$, and $\gamma=-1.57545$ equals $-\frac12d^2(1+q^2)$; the values from $H_{24}$ and $H_{34}$ agree to $10^{-13}$. \begin{notebox}
\textbf{Things to know.}
\begin{itemize}
  \item \textbf{Units.} $Z$ is per unit of $t$, normalised by $Z^{\mathsf T}U'=1$. To express it per unit of phase on $[0,1)$ divide by $T$; on $[0,2\pi)$ multiply by $2\pi/T$. Only the horizontal axis is scaled to $t/T$, so that orbits of different periods share one axis. The functions $g_1$, $g_2$, $g_3$ are in units of time per unit time, with the horizontal axis $\phi/T$.
  \item \textbf{The coupling is $\epsilon\,G(X,X')$,} for a pair of identical cells, with $G$ in the \texttt{\#@coupling} lines and $\epsilon$ outside the equations. $\epsilon$ is entered only in the $H_2$ field. A strength written inside a line is part of $G$.
  \item \textbf{Floquet multipliers.} $I$, $\rho$, $B$ and $H_2$ need a real, positive slowest multiplier $\nu_1$ that is not too close to~1 or to zero; see the box above for the cases that are skipped. The second-order theory also assumes that the other multipliers are much smaller than $\nu_1$.
  \item \textbf{Near a Hopf point} the orbit shrinks and $Z$ grows like $1/\text{amplitude}$ (for the Stuart--Landau oscillator, as $1/\sqrt\mu$), and very close to the point it is meaningless; $\nu_1$ is then near~1 and the isostable functions are skipped as well. Unless you give a range or values with \texttt{at=}, orbits with an amplitude below 3\% of the largest in the family are left out, and the status line says so. An orbit whose $Z$ is more than 8 times the typical size is left off the plot while the window is the automatic fit, and the key names it. Set the window with \ui{Window}, or zoom, and every curve is drawn; \ui{Fit} returns to the automatic fit. A range such as $100$ to $200$ for Morris--Lecar keeps the family away from both Hopf points.
  \item \textbf{Limits.} The phase reduction is for differential equations without delays or Volterra integrals, with at most 60 variables ($B$, and so $H_2$, at most 24), and for models that do not depend on $t$ explicitly (the same restriction as for continuing orbits). The \emph{Current periodic orbit} choice finds stable orbits only. $Z$, the isostable functions and the orbits are not updated when the parameters or the family change, so press \ui{Adjoint} again after a change that alters the cycle ($H$ and $H_2$, which only use them, are recomputed).
  \item \textbf{Recording.} With \ui{Record} on, the chips of this view are recorded as \texttt{phasefn} lines, and the field for $\epsilon$ as \texttt{hsecond eps=}.
\end{itemize}
\end{notebox}

\section{Numerical settings}\label{sec:numerics}

\begin{figure}[!htbp]
  \centering
  \includegraphics[width=0.42\textwidth]{ui-numerics.png}
  \caption{The Numerics tab: integration settings at the top, continuation settings below, and the continuation tolerances (Section~\ref{sec:numerics}) further down.}

The \ui{Numerics} tab (Figure~\ref{fig:numerics}) collects the integration and continuation parameters. Changes to the integration settings rerun every trajectory on screen (when \ui{Auto-update} is ticked; see below).

\paragraph{Integration.}
\begin{description}[font=\sffamily\bfseries]
  \item[Method] As in Section~\ref{sec:language}.
  \item[Total time] The duration of each run; for maps, the number of iterations.
  \item[Transient] As in \XPP{}, the run still lasts the total time, but only $t\ge$ the transient is kept (\texttt{@ trans=}). Use it to look at attractors without the approach to them. Manifolds and the single periods loaded from continuation are never cut.
  \item[dt] The step for fixed-step methods, and the largest step for adaptive ones.
  \item[Tolerance] Applies to the adaptive methods.
  \item[Bound] Integration stops when any variable exceeds this value.
  \item[Direction] Forward, backward or both ways in time (also next to \ui{Integrate} in the Initial tab).
  \item[Start time] The start time $t_0$ of each run (\texttt{@ t0=}).
  \item[Nullcline grid] Sets the resolution of the nullclines.
  \item[Sweep samples] Sets the number of parameter values in \ui{Sweep max/min}.
\end{description}

\paragraph{Auto-update, Run and long computations.}\label{sec:autorun} By default, changing a parameter, an initial value or an integration setting runs the trajectories again at once, so that the figure always matches the values shown. That is what makes sliders so useful, but it is a nuisance in two situations: when you want to change three parameters and not wait for a run after the first, and when the system is large enough for a run to take seconds. Unticking the \ui{Auto-update} box at the top of the window turns it off.
\begin{itemize}
  \item \textbf{With Auto-update unticked,} a change only marks the display as out of date. A label on the plot says \emph{Out of date: press Run} (or \emph{Not run yet} if nothing has been computed) and \ui{Run} is highlighted. Nullclines and the direction field still follow the parameters, because they are cheap; trajectories and equilibria wait for \ui{Run}.
  \item \ui{Run} brings everything up to date: the active curve follows the new initial values, the other curves are recomputed with the new parameters and settings, and the equilibria are found again. If nothing is out of date it does what \ui{Integrate} does. Ticking Auto-update again while the display is out of date runs at once.
  \item \ui{Integrate} (or \key{G}) still adds a new trajectory from the initial values; if the other curves are out of date, they are recomputed first, so a new curve never sits next to curves made with other parameters.
  \item \textbf{The default depends on the size of the system.} Auto-update is ticked for up to 40 variables, the same limit above which equilibria are no longer searched for automatically, and off above it. Loading a chain of 200 cells (400 variables) therefore computes nothing until you press \ui{Run}, and the status line says so. You can tick it for such a model if you wish. Your choice to untick it is remembered between sessions, and \ui{Reset all} ticks it again.
\end{itemize}
\noindent A run that takes more than a fraction of a second shows its progress in the status line, for example \emph{Running\ldots{} 34\%, t = 340}, with a \ui{Stop} button at its right-hand end, and the percentage is also shown in the title of the browser tab, so you can watch it from another tab. \ui{Stop} ends the run where it is and keeps the part already computed. If you change something while a run is going, the old run is abandoned and a new one starts with the new values, so dragging a slider on a large system always ends with curves that match its final position. Short runs finish before any of this appears, so small systems behave exactly as before.

\begin{notebox}
Only ordinary differential equations are run in this way. Maps, delay equations, Volterra equations, models with Markov or Wiener variables, and models with global flags are always computed in one piece, as before; they have no progress line or \ui{Stop}, although Auto-update and \ui{Run} work for them. The time is dominated by the right-hand side: a chain of 200 FitzHugh--Nagumo cells with \texttt{meth=euler} and many thousands of steps can take several seconds, mostly in evaluating the equations. Raising \texttt{dt}, lowering the total time or plotting fewer steps helps more than any setting.
\end{notebox}

\paragraph{Continuation.} These settings correspond to the entries of \XPP{}'s \textsf{AUTO} numerics window and can be set in the file with \texttt{@ ds, dsmin, dsmax, nmax, ntst, parmin, parmax}. Leave a box empty to use the automatic choice. \ui{Defaults}, next to the heading, puts them back to the model's defaults: the values its file sets, otherwise the built-in ones. A step set with \texttt{@ ds} applies to every parameter; otherwise Ds is a $1/150$ of the parameter's range. The \ui{Wilson--Cowan} example sets \texttt{@ ds=0.01}, since its branches have sharp folds that a larger step cuts across.

\paragraph{Continuation tolerances.} Each step of a continuation predicts the next point along the tangent and corrects it with Newton's method. The correction stops when its size falls below a tolerance, and the point is then accepted only if the equations hold to within the residual tolerance; otherwise the step is halved. The section \ui{Continuation tolerances} of the Numerics tab sets these, and its \ui{Defaults} puts them back to the model's defaults. The file can set them with \texttt{@ eqtol, potol, tptol, restol, itmax, tgrow}, and \ui{Write state} writes those that differ from the defaults.
\begin{center}\small
\begin{tabularx}{0.95\textwidth}{@{}llX@{}}
\toprule
Setting & Default & Effect\\
\midrule
Newton tol (eq.) & $10^{-10}$ & last Newton correction for branches of equilibria and fixed points, relative to the size of the solution (\texttt{eqtol}, like \textsf{AUTO}'s EPSU)\\
Newton tol (orbits) & $10^{-9}$ & the same for periodic orbits, in the scaled unknowns of the shooting method (\texttt{potol})\\
Newton tol (2-par) & $10^{-8}$ & the same for two-parameter curves of folds, Hopf points and bifurcations of cycles (\texttt{tptol})\\
Residual tol & $10^{-6}$ & largest residual of the equations at an accepted point; for orbits, relative to their size (\texttt{restol})\\
Newton iterations & automatic & most Newton iterations per step before the step is halved: 15 for equilibria, 14 for orbits and two-parameter curves, 12 for curves of cycles (\texttt{itmax}, like \textsf{AUTO}'s ITNW)\\

\bottomrule
\end{tabularx}
\end{center}
Tighter tolerances give more accurate points and usually smaller steps; looser ones can carry a branch through a stretch where the corrector struggles, at some cost in accuracy, so check such a branch against a tighter run. Raise the period growth stop to follow orbits closer to a homoclinic orbit.

If a branch stops early, the status line says why: for example, it reached the point limit, the corrector stopped converging, the orbit shrank onto a Hopf point, or the period grew without bound (a homoclinic orbit is near). If it stopped because of a step-size or point limit, adjust the corresponding setting and run it again. A branch of orbits whose period grew to its end is examined (Section~\ref{sec:conn}): the saddle it approaches is loaded into the homoclinic search, or, if the orbits end at a fold of the equilibria, the fold is marked as a probable SNIC.

\section{Saving and exporting results}\label{sec:export}

\begin{description}[font=\sffamily\bfseries]
  \item[Export SVG] Saves the current view as a vector figure with light-theme colours, ready for a paper or for editing in Inkscape or Illustrator. Legends and notes are included. All the plots in this document were made this way.
  \item[Export CSV] Available in the Time course, Bifurcation and Two-parameter views.
  \begin{itemize}
    \item The time-course table has every trajectory on screen, one row per stored point, with the trajectory number, its kind (trajectory or manifold), its direction (forward or backward), $t$ and every variable.
    \item The bifurcation table has one row per computed point, with these columns: curve, kind (equilibrium, periodic orbit, sweep or special), label (HB1, LPC2, \ldots), parameter name and value, stability, number of unstable directions, period, the state, and the maximum and minimum of each variable along an orbit.
    \item The two-parameter table has the two parameter values, the period where relevant, the state, and labelled rows for codimension-two points. Hopf curves also get columns for $\ell_1$ and for criticality (subcritical, supercritical or neutral saddle).
    \item In the bifurcation table, special rows for Hopf points give $\ell_1$, and the stability column says subcritical or supercritical.
  \end{itemize}
  \item[Export DAT] In the Bifurcation and Two-parameter views, saves the same continuation data as \texttt{.dat} files: numbers only, no header and space-separated columns, the form \XPP{} and gnuplot read. The bifurcation diagram gives one file each for equilibria, periodic orbits and sweeps. The status line lists the columns, and text fields become numeric codes.
  \item[Copy CSV, Save DAT] In the trajectory list, copy the current trajectory (time, variables and auxiliaries) to the clipboard, or save it as a \texttt{.dat} file.
  \item[Copy text] Copies the \texttt{.ode} file, including any edits, so that it can be saved or used in \XPP{}.
\end{description}

\subsection*{Writing the current state into the file}\label{sec:writestate}
After exploring a model you will often want to keep the parameter values and settings you have arrived at. \ui{Write state}, in the Equations tab, writes them into the \texttt{.ode} text, much as \XPP{} does when it saves a file:
\begin{itemize}
  \item parameter values and initial conditions are changed where they are defined, in the \texttt{par}, \texttt{init} and \texttt{x(0)=} lines, as are slider ranges in \texttt{\#@range} lines and history formulas of delay equations;
  \item the integration settings (method, total time, step, transient, tolerance, bound, random seed), the plot axes and window, and the continuation settings are collected in \texttt{@} lines just before \texttt{done}.
\end{itemize}
For example, after setting $i=150$ and a transient of 100 in the Morris--Lecar example, the end of the file reads
\begin{lstlisting}
param i=150,c=20
...
# Settings written by XPP Studio, 2026-10-20 10:30
@ meth=rungekutta, total=400, dt=0.25, trans=100, bound=10000
@ xp=v, yp=w, zp=ica, xlo=-75, xhi=45, ylo=-0.1, yhi=0.55
@ ds=2, nmax=3000, parmin=0, parmax=300
done
\end{lstlisting}
Pressing \ui{Write state} again replaces this block rather than adding another, and \ui{Apply} on the result restores exactly the same state. The text is not reloaded, so the trajectories on screen are kept. Use \ui{Copy text}, or your browser's own storage of the editor, to keep the file. Parameters defined through array lines are left as written.

\section{Differences from \XPP{}}

\XS{} aims to read the same files and to feel familiar, but it is a reimplementation:
\begin{itemize}
  \item \textbf{Continuation.} It is built in and written from scratch: pseudo-arclength continuation of equilibria, and multiple shooting (rather than \textsf{AUTO}'s orthogonal collocation) for periodic orbits. Results agree with \textsf{AUTO} to plotting accuracy on the examples, but very long or very unstable orbits may need more shooting intervals (Ntst).
  \item \textbf{Delay equations} are integrated with a fixed step only, and periodic orbits of delay equations cannot be continued. \XPP{}'s other delay options, such as \texttt{delshft} and \texttt{ndelay}, are not supported. The \texttt{@ delay} option is accepted but not needed, since all of the history is kept.
  \item \textbf{Global flags} can set state and Markov variables and \texttt{arret}. The XPP output flag \texttt{out\_put} is accepted and ignored.
  \item \textbf{Sets.} \XPP{}'s \texttt{set name \{\ldots\}} lines are read and offered in the \ui{Sets} menu (Section~\ref{sec:sets}), except that the plot settings in them (axis limits and plotted variables) are ignored.
  \item \textbf{The adjoint} (Section~\ref{sec:adjoint}) is found from the monodromy matrix of the orbit rather than by integrating the adjoint equation backwards over many periods as in \XPP{}. It works for unstable orbits as well, it is computed along a whole family at once, and it is limited to differential equations with at most 60 variables. The isostable response, Floquet eigenfunction and the second-order interaction functions have no counterpart in \XPP{}; they are computed for a real, positive slowest multiplier only. The interaction function $H$ (Section~\ref{sec:hfun}) is computed from \texttt{\#@coupling} lines in the file, which \XPP{} reads as comments, rather than from \XPP{}'s averaging window.
  \item \textbf{Not supported:} \texttt{special} and \texttt{export} declarations.
  \item \textbf{Two-parameter Hopf curves} are limited to 12 variables, because the bialternate product grows quadratically with dimension.
  \item \textbf{Homoclinic and heteroclinic orbits} (Section~\ref{sec:conn}) are found by shooting along the one-dimensional unstable manifold of a saddle, not by \textsf{AUTO}'s \textsf{HomCont} projection boundary conditions, so they are limited to saddles with one real unstable direction (or one real stable direction, with time running backwards).
  \item \textbf{Volterra models} cannot be continued, since their state is infinite-dimensional.
  \item \textbf{Browser files.} Files are opened and saved through the browser. Table data files are kept in the browser's local storage until you press \ui{Forget table files}.
\end{itemize}
