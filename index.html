Supported .ode syntax
  • x'=… or dx/dt=… differential equations
  • x(t+1)=…, or x'=… with @ meth=discrete, for maps (iterated and drawn as points)
  • wiener w declares white noise for an SDE such as x'=-x+s*w (Euler–Maruyama; @ seed=7 repeats a noise path)
  • @ fold=th, tor_per=6.2832 makes a variable periodic (repeat fold= for more)
  • @ meth=stiff (also gear, cvode, rosenbrock, backeul) selects the Rosenbrock stiff solver
  • x(0)=…, init x=1, y=0 initial values
  • par a=1, b=2 parameters · number c=3 constants · !d=a*b derived
  • f(x,y)=… functions · q=… fixed quantities · aux s=… outputs
  • @ total, trans, dt, meth, xp, yp, zp, axes=3, xlo…yhi, bound, toler; trans=50 keeps only t ≥ 50 of each trajectory
  • @ ds, dsmin, dsmax, nmax, ntst, parmin, parmax set the continuation numerics (also editable in the Numerics tab)
  • sin cos tanh exp ln sqrt abs heav max min mod atan2, if(c)then(a)else(b)
  • #@range p lo hi sets a slider range (a comment, so XPPAUT ignores it)
  • markov z 2 followed by rows {0} {kon} and {koff} {0}: a Markov variable; entry (i,j) is the rate of jumping from state i to j
  • table h % 101 0 6.283 sin(t) samples an expression; table h data.tab reads a file of npts, xlo, xhi, then the values (add files with “Table files”); lookups interpolate linearly
  • x[1..20]'=-x[j]+x[j-1] arrays: the line is repeated for j = 1…20 and each [expr] becomes its value; %[1..20] … % repeats a block of lines; init x[1..20]=0
  • int{K(t,t',x)} is ∫₀ᵗ K dt′ with the variables at t′; int{K#x} is the convolution ∫₀ᵗ K(t−t′)x(t′)dt′ with K written in t; int[mu]{…} adds the weight (t−t′)^(−mu); u(t)=…int{…} or volterra u=… defines an integral equation; @ vmaxpts=4000 sets the memory
  • delay(x,tau) is x(t − tau); tau may depend on the state. x(0)=sin(t) gives the history for t < 0 (also editable in the Initial tab); otherwise it is constant
  • global 1 x-1 {x=0;y=y+1}: when x−1 crosses zero upwards (1), downwards (−1) or either way (0), make the assignments; arret=1 stops the run
Drag a slider: trajectories, nullclines and equilibria update live.

Clicking the phase plane also sets the initial condition. Variables off the plotted plane keep these values, and nullclines are drawn on that slice.

Continuation

As in XPP's AUTO numerics menu. Leave a box empty for the automatic choice. The file can set these with @ ds, dsmin, dsmax, nmax, ntst, parmin, parmax.

Tolerance applies to the adaptive methods; for them dt is the largest step. Integration stops when any variable exceeds the bound. Shift-click in the phase plane integrates both forward and backward.
